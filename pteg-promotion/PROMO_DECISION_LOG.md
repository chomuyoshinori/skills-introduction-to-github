# プロモーション決定ログ(Decision Log)

チームが出した提案・副社長の上申・社長の決定・その根拠と検証予定を記録する。
PDCAの「P」の記録であり、後で `pteg-kaizen-reviewer` が実績と照合(C)して
`PROMO_LESSONS.md` に教訓を蓄積(A)するための土台。

## 記録フォーマット
```
## YYYY-MM-DD 〔案件名〕
- 提案: 〜(提案書: pteg-promotion/proposals/xxx.md)
- 副社長の上申・対案: あり(内容の要約)/なし → 社長の採否
- 社長決定: 採用 / 修正採用(修正内容) / 却下 / 保留
- KPI・成功基準: 〜 | 反証条件(どうなったら見立てが間違い): 〜 | 検証予定: YYYY-MM-DD頃
- 結果(後日追記): 成功/失敗/検証不能 — 実際どうだったか / 判断プロセスは正しかったか
```

## 重要な考え方
- 「うまくいったか(結果)」と「判断の論理が正しかったか(プロセス)」を分けて記録する。
- 却下された上申・対案も必ず記録する。後から対案が正しかったと分かることが最大の学習機会。
- KPI・反証条件のない決定は記録として不完全(後で検証できない)。
