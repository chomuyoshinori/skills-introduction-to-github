PTEG = 経皮経食道胃管挿入術(Percutaneous Trans-Esophageal Gastro-tubing)。
PEG(胃瘻)が困難な症例に対する経腸栄養・消化管減圧のための日本発の手技。
(医学的記述は最終的に世話人・事務局の監修を受けること)

## 2. プロモーションの核となるストーリー
- 全体コンセプト: **「北海道から、次の未来へ。」**
- 単なる北海道観光PRではなく、**「札幌で開催される学術集会」と「世話人の想いがある十勝清水」を、
  地域・地域医療・PTEG・ケアの未来という一本のストーリーでつなぐ。**
- 地域の恵み(農・畜産)→ 地域の力 → 人を支える医療 → PTEG・ケアの近未来、という流れ。

## 3. 表現ルール(全制作物で必須遵守)
既存の公式制作物(ポスター・30秒PR動画制作指示書)で確立されたルール。
**違反は副社長ゲートで差し戻しになる。**
1. 開催地は**札幌**であることを明確にする。十勝清水は「世話人の地域」として扱う。
2. 十勝清水の農産物は**小麦・じゃがいも・にんにく**を使用する。**玉ねぎは使用しない。**
3. 畜産ブランドは**十勝若牛**を使用する。
4. 公式ポスターは**元画像を改変せずそのまま**使用する。
5. 日本語の文字・ロゴを画像/動画生成AIに描かせない(テキストは編集工程で正確に配置する)。
6. トーン: 医療学会公式らしい品格・知性・信頼感・温かみ。観光CMのように明るすぎない。誇大表現禁止。
7. 学会テーマ表記「地域・PTEG・ケアの近未来」を一字一句正確に使う。会期・会場・名称は本ファイル§1と照合する。
