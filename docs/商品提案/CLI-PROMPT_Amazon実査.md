# ローカルClaude Code用プロンプト — Amazon競合実査(スクショ収集)

使い方: ローカルPCでこのリポジトリをclone/pullし、リポジトリ直下で `claude` を起動して以下を丸ごと貼り付ける。
ブラウザが開いたらbot確認(画像認証)が出た場合だけ手動で解除する。

---

```
Amazonの競合実査を行い、スクリーンショットとデータをこのリポジトリに保存してほしい。

## 前提
- ブランチ claude/ikea-rudsta-plant-greenhouse-nyosac をチェックアウトして作業する
- 背景資料: docs/商品提案/2026-07-09_Amazon競合調査.md の「要実査リスト」を先に読むこと
- Playwright(なければ npm i -D playwright && npx playwright install chromium)で
  **headed(ヘッドフルー)モード**のChromiumを使う。bot確認が出たら私が手動で解除するので
  ページを開いたまま待つこと。ページ間は3〜5秒待機し、並列アクセスはしない

## 撮影対象
A. 検索結果1ページ目(PC表示・全体スクロールスクショ):
   「室内温室」「温室 ガラス」「パルダリウム ケージ」「ビカクシダ ケース」「植物育成ライト 棚」
B. 商品ページ(以下のASIN+検索上位で気になった商品2〜3件を追加):
   - B00E0GLLKI(GEX グラステラリウム9045)
   - B07BVQ3PV8(タカショー グリーントラッグ LGT-03W)
   - B0FF1L2CMY(ビザールプランツラック)
   - B07J6885Y8(EC Grow グロウテント)
C. 各商品ページで個別に切り出して撮るもの:
   1. ファーストビュー(タイトル・価格・クーポン)
   2. 「過去1ヶ月で○点以上購入されました」バッジ付近(なければ「なし」と記録)
   3. 商品情報欄のAmazon売れ筋ランキング(BSR)
   4. レビューサマリー(平均星・件数・星の分布)
   5. 星1〜3のレビューを絞り込み、上から3ページ分

## 保存・記録
- 画像は docs/商品提案/assets/amazon-<今日の日付YYYYMMDD>/ に保存。
  命名: <検索KWまたはASIN>_<firstview|badge|bsr|reviews|low1|low2|low3>.png
- docs/商品提案/assets/amazon-<日付>/README.md に一覧(ファイル名/何のスクショか/撮影日時)を書く
- 同時に docs/商品提案/2026-07-XX_Amazon実査データ.md を新規作成し、商品ごとに
  「ASIN/商品名/価格/クーポン有無/購入バッジ数/BSR(カテゴリと順位)/星平均/レビュー件数/
  出荷形態(FBAか出品者出荷か)/星1〜3の不満の要約(品質・説明・サイズ・梱包・付属品・デザインに分類)」
  の表とメモを書く

## 注意
- レビューへの操作(投稿・依頼・通報)は一切しない。閲覧とスクショのみ
- スクショは社内・コンサル提出資料用。公開資料への転載はしない旨をREADMEに明記
- Amazonに負荷をかけない(待機を入れ、対象は上記に限定)

## 完了後
- git add → commit(メッセージ: 「Amazon実査: スクショ+生データ <日付>」)→
  ブランチ claude/ikea-rudsta-plant-greenhouse-nyosac に push
- 最後に、撮れたもの/撮れなかったもの(bot壁・在庫切れ等)を一覧で報告して終了
```

---

push後、リモート側(このセッション)に「実査データを上げた」と伝えれば、
トリミング・注釈入れ・競合調査資料への画像組み込み・提案書の「要実査」欄の確定まで引き継いで行う。
