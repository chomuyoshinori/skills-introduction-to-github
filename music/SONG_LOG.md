# SONG LOG — 楽曲企画の記録

各曲の企画時の「狙い・バズ仮説・確信度・反証条件」を記録する。公開後に `release-retrospective-reviewer` が実績と照合して学習に使う。

記録フォーマット:
```
## YYYY-MM-DD — [曲タイトル]
- 狙い: 〔ジャンル/フォーマット〕 | 言語比率: 日X:英Y | 確信度: 高/中/低
- バズ仮説: 〜 | 反証条件(滑るとしたら): 〜 | 公開予定/実績リンク: 〜
```
