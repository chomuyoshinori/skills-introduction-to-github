# 初心者向け:Suno曲を縦動画(TikTok/Shorts)にする手順

> 作るもの =「**①動く背景 + ②歌詞の文字 + ③曲**」をCapCutで重ねた縦動画(9:16)。スマホ1台でOK。
> 例として「Doobie Scoot Tokyo」を使うが、どの曲でも同じ手順。

## 準備するもの(すべて無料枠あり)
- **Suno**(曲のダウンロード)— すでに使用中
- **動く背景を作るAI**:Kling(klingai.com)または Luma Dream Machine。どちらか1つでよい
- **CapCut**(無料の動画編集アプリ。スマホ版が一番かんたん)

---

## STEP 1:曲をダウンロードする(Suno)
1. Sunoで自分の曲のページを開く。
2. 曲の「…」メニュー →「Download」→「**MP3 Audio**」を選ぶ。
3. スマホ/PCに曲ファイルが保存される。✅これで素材①完了。

## STEP 2:動く背景を1本つくる(画像先行=おすすめ)
> テキストから直接動画は精度が低い。**まずChatGPTで「動かない1枚絵」を作り**、それをAIで動かすと、思い通りで崩れにくい。

### STEP 2A:ChatGPTで背景画像を作る
1. ChatGPTを開く(画像生成=GPT-4o)。
2. 下の指示をそのまま送る:
   ```
   縦長(ポートレート)の画像を1枚作って。
   内容:夜の東京の裏路地を一人称視点で歩いている構図。ネオンサイン、自販機の光、
   濡れたアスファルトの反射、奥に横断歩道。手前の下に自分のスニーカーが少しだけ見える。
   アニメ調のシティポップなイラスト、暖色アンバー＋寒色シアンのネオン、
   ノスタルジックでエモい雰囲気、フィルムの粒状感。
   看板やロゴの文字は読めないようにぼかして(文字は入れないで)。
   ```
3. 出てきた絵を見て、足りなければ言葉で直す:「もっと夜にして」「もっと縦長に」「文字を消して」など。
4. 気に入ったら**画像を保存(ダウンロード)**。
   - ポイント:**文字は入れない/ぼかす**(AIの文字は崩れる＆動かすと余計に崩れる)。
   - 別シーンが欲しい時:「同じ画風で、今度は"雨の日""始発の駅""コンビニ前"」と頼むと統一感が出る。

### STEP 2B:その画像を動かす(Kling または Luma=Image to Video)
1. Kling(klingai.com)か Luma にログイン。
2. 「**Image to Video**(画像から動画)」を選ぶ。
3. STEP 2Aの**画像をアップロード**。
4. 動きの指示をコピペ:
   ```
   Animate this image: slow first-person forward walk, gentle camera bob like footsteps, neon signs flicker softly, vending machine glow pulses, light reflections shimmer on the wet street, faint drifting steam, keep the original art style, calm cinematic, minimal subtle motion, seamless loop
   ```
5. ネガティブ欄があれば:
   ```
   morphing, distorted, warping text, jitter, fast motion, scene cut, extra people, melting
   ```
6. 長さ**5秒**、できれば**「始点=終点フレームを同じ画像」**に設定(Lumaは**Loop ON**が最速)。
7. 「Generate」→ 数分待つ。**3〜5回**作って一番崩れない版を選ぶ。
8. **ダウンロード**。✅これで素材②完了。

（さらに簡単に済ませたい時だけ:Text to Videoで一発生成も可。ただし精度は落ちる）

## STEP 3:CapCutで合体させる(ここが本番)
1. CapCutアプリを開く →「**新しいプロジェクト**」。
2. STEP2の背景動画を読み込む。
3. 右下などの**比率(Ratio)を 9:16(縦)** に設定。
4. **背景を曲の長さまで伸ばす**:背景クリップを選び「コピー」して並べる(5秒を繰り返してループにする)。または長さを引き伸ばす。
5. **曲を入れる**:「オーディオ」→「追加」→STEP1のMP3を選ぶ。
6. **文字(歌詞)を入れる**:「テキスト」→「追加」→歌詞を打ち込む。
   - 曲を聞きながら、**その歌詞が流れる位置に文字を置く**(文字クリップを左右に動かして合わせる)。
   - サビ「DOOBIE SCOOT TOKYO」は**大きく**、日本語は別の色/書体にすると「日英ミックス感」が出る。
   - ⏱️**時短ワザ**:「テキスト」→「**自動字幕(キャプション)**」を使うと、AIが歌声を聞いて字幕を自動で作る。ズレや誤字だけ直せばよい(全部手打ちより圧倒的に速い)。
7. **冒頭3秒が勝負**:0秒の位置に、いちばん大きく「DOOBIE SCOOT TOKYO」を出す。無音・真っ暗で始めない。
8. **書き出し(エクスポート)**:右上の「↑」→ **1080p / 30fps** で保存。✅完成。

## 詳細版:スマホCapCut タップ手順(初投稿用・約25〜30秒)
> 準備:背景(Klingで動かした5秒クリップ。無ければSTEP2Aの静止画でOK)＋曲のMP3(STEP1)。

**A. プロジェクトを作る**
1. CapCutを開く →「**+ 新しいプロジェクト**」。
2. 背景(動画 or 画像)を選ぶ →「**追加**」。
3. 縦か確認(下メニュー「**比率**」→ **9:16**)。横素材なら9:16にして、指で背景を広げ全画面に。

**B. (静止画の人だけ)動きを足す**
4. 背景クリップをタップ →「**アニメーション**」→ ゆっくりズーム系。
   - 無ければ**キーフレーム**:再生位置を先頭へ→◇を押す→末尾へ動かし→背景を指で少し拡大。「ジワッと寄る」動きになる。

**C. 曲を入れて長さを決める**
5. 何もない所をタップ →「**オーディオ**」→「**サウンド**」→「**デバイスから**」→ STEP1のMP3。
6. 使う区間(イントロのサビ)に合わせ、曲を「**分割**」→ いらない前後を「**削除**」。約25〜30秒に。
7. 背景も同じ長さに(「**コピー**」して並べる or 端を引っぱる)。

**D. 歌詞テキストを乗せる(主役)**
8. 「**テキスト**」→「**追加**」→ サビ入力(例 `DOOBIE SCOOT TOKYO`)→ 大きく・中央上に。
9. その文字を、歌が流れる位置へ左右に動かす。行ごとに8を繰り返す。
   - ⏱️時短:「テキスト」→「**自動キャプション**」で歌声から字幕を自動生成。造語/日英混在は誤認識多め→**サビは手打ち**が確実。
10. 文字を弾ませる:文字を選び「**アニメーション**」→ 入場「**バウンス/ポップ**」。

**E. 掴みと締め**
11. **0秒**に特大 `DOOBIE SCOOT TOKYO`(真っ暗・無音で始めない)。
12. **最後の3秒**にエンドカード `意味わからんけど好きすぎる` ＋ `君の聞き間違いは?`。

**F. 書き出し → 投稿**
13. 右上「**↑書き出し**」→ **1080p / 30fps** → 保存。
14. TikTok →「**+**」→「**アップロード**」→ この動画 → キャプション貼り付け。
15. 投稿前設定で「**AI生成コンテンツ**」を**ON**。
16. 投稿後、自分でコメントを書いて**長押し →「ピン留め」**(呼び水)。

## いちばん簡単な「最速ルート」(今日中に出したい人)
1. STEP2の背景5秒を1本だけ作る。
2. CapCutで背景をループ＋曲を入れる。
3. **自動字幕**で歌詞を一括表示(手直しだけ)。
4. 書き出して投稿。
→ 凝った演出は後回し。まず1本出して反応を見るのが上達の近道。

## つまずきポイントQ&A
- **背景のAIが変な動きをする** → 動きを少なくしたいので、プロンプトに「minimal subtle motion」を残し、長さを5秒に。3〜5回生成して選ぶ。
- **文字が小さくて読めない** → スマホ画面で見て読める大きさに。背景が明るい所は文字に黒フチ/影を付ける。
- **曲と歌詞がズレる** → 自動字幕で土台を作ってから微調整すると楽。
- **縦にならない** → CapCutの比率を必ず 9:16 に。AIの背景も9:16で作る。
- **AIだと公開して大丈夫?** → TikTokは「AI生成コンテンツ」表示をON、説明欄に「Created with Suno / Kling(Luma) AI」と一言。

## 必要なアプリ/サイト
- 曲:Suno(ダウンロード)
- 背景:Kling(klingai.com)/ Luma(Dream Machine)/ ※CapCut内のAI機能でも可
- 編集:CapCut(無料・スマホ/PC)。代わりに Canva や InShot でも近いことができる
