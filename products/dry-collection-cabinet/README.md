# 防湿コレクションケース「(仮称)ドライキャビネット」企画書 v0.1

グロウキャビネット(`products/indoor-greenhouse-cabinet/`)と**同一プラットフォーム**で作る、
「魅せる」防湿コレクションケース。湿度制御の方向が逆(加湿環境の維持→除湿)なだけで、
本体・密封・電装アーキテクチャ・マグネットシステムは共通。

## 1. コンセプト

**「防湿庫の性能を、飾れる家具の見た目で。」**

- 既存の防湿庫(カメラ用)は性能はあるが**見た目が業務用の鉄箱**で、リビングに置いて飾るものではない。
- 既存のコレクションケース(RUDSTA/DETOLF等)は見た目はいいが**湿度もライティングも無管理**。
  日本の夏はRH70%超 — カビ(レザー・箱物)、トレカの反り・湿気ダメージ、プラモデカールの劣化が起きる。
- その中間 =「湿度40〜50%を自動維持し、照明で魅せて、状態も守る」ケースが市場空白。
  グロウキャビネットと同じ「ポジショニングの右上(インテリア性×完成度)」戦略。

## 3. プラットフォーム共通/差分

### 共通(グロウキャビネットv0.3の設計・図面・工場をそのまま使う)
- 本体: W800×D370×H1200(KD・スチール+強化ガラス5mm・粉体塗装黒)— **同一金型・同一治具・同一工場**
- 全シール工場装着(扉ガスケット+KD接合部圧縮シール)— 防湿では密封が生命線なのでそのまま活きる
- 機器収納ベイ+配線ポート6口+盲栓 — 除湿ユニットの配線・アダプター収納に流用
- マグネット壁面(背面・天井スチール、ドットグリッド)+EBOX+レースウェイ+フック磁石
- EBOXのUSBポート — ウォッチワインダー・装飾ネオン・センサー等の「遊び給電」にそのまま使える

### 差分(防湿版で変える4点)
| # | 項目 | 内容 |
|---|---|---|
| D1 | **除湿ユニット(新規・中核部品)** | ペルチェ式除湿モジュール(防湿庫用のカタログ部品。中国にドライキャビネット専業工場が多数)。DC24V・湿度センサー連動のヒステリシス制御(設定RH±5%)。背面下部P3ポート位置に装着し、湿気は庫外へ排出。目標: 庫内RH 35〜55%可変、外気RH80%時にRH45%維持 |
| D2 | **ライティング(育成→展示用に変更)** | 高演色 Ra≥95・UVカットのディスプレイ照明。①天井スポットライト×3(マグネット・首振り)②棚下ライトバー(調色2700〜5000K・調光)。「魅せる」の主役。DC24V・タイマーはハブ流用 |
| D3 | **棚の復活** | 植物版と違い棚が主役。ガラス棚×3(框エッジ・ダボ)+マグネット小棚(既製ラック流用)+ひな壇(アクリル・オプション)。※棚ダボ穴が本体側の唯一の板金変更点 → 共通化のため**グロウ版にもダボ穴を最初から開けておく**(未使用でも支障なし) |
| D4 | **ベント廃止・UVカット** | スライドベントは防湿に不利 → 盲蓋に置換(板金は共通、蓋部品のみ変更)。オプションでUVカットフィルム貼りガラス(トレカ・箱物の日焼け対策) |

- 底面の防水パン・トレイは不要だが、板金共通化のためパンはそのまま(気密には無害)。トレイ・水切りマットを同梱から外す。

## 5. 技術リスク(グロウ版より1つ増える)

1. **除湿性能の実証が最重要**: 約240Lは防湿庫として大容量。ペルチェ1基で梅雨時にRH45%を維持できるか
   → 試作で「扉開閉テスト(1日3回開閉)後の回復時間」を計測。必要なら2基構成(P3ポートが左右にあるのはここで活きる)
2. 結露水の処理: ペルチェの凝結水は庫外排出(防湿庫標準方式)。ユニットのカタログ選定条件に含める
3. 消費電力: ペルチェは連続駆動で10〜20W級 → 電気代訴求はグロウ版より弱い(月300〜500円)。ヒステリシス制御で抑制
4. 「密封+除湿」はガラス内面の結露リスクが低く、アクリル不可の理由(§SPEC-00 7.5)のうち「拭き傷」が弱まる —
   **防湿版に限りアクリル軽量変種の検討余地あり**(v2)

## 6. 競合(簡易)

| 競合 | 弱点 |
|---|---|
| 東洋リビング/HAKUBA等の防湿庫 | 性能は本物だが業務用の見た目・展示照明なし・「飾る」発想がない |
| IKEA RUDSTA/DETOLF+乾燥剤 | 湿度は成り行き(乾燥剤は密封が甘いと数日で飽和)・照明別途 |
| コレクションラック(ニトリ等) | 湿度・防塵なし |
| ゲーミング系ショーケース(LED付き) | 光るだけ。保存環境の思想がない |
