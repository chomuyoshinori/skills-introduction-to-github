## 5. 設計方針(全部品共通)

1. **無加工取付**: キャビネット本体への穴あけ・ネジ止めを要求しない。固定はネオジム磁石(背面スチール)と粘着(VHB相当)のみ。
2. **電源はDC集中方式**: AC→DC変換はPSE認証済みACアダプター1個のみ。庫内に入る機器はすべてDC24V/5V。
   庫内は高湿度(常時RH70〜90%)のため、庫内機器は防湿仕様(基板コンフォーマルコーティング等)を必須とする。
3. **環境条件**: 動作温度 5〜40℃ / 湿度 〜95%RH(結露あり得る)。この条件での連続稼働(ファンは24h365日)を前提に部品選定。
4. **意匠**: 艶消し黒(RAL9005近似)で統一。RUDSTAチャコールに馴染ませる。
5. **RoHS準拠**(全部品)。梱包・取説は日本語。

## 7. スケジュール目安

1. RUDSTA実機購入・実測(1週) → ★要実測値の確定
2. サプライヤー選定・サンプル依頼(2〜3週)
3. サンプルで実機適合試験+高湿度耐久試験(2〜4週)
4. 量産(4〜6週)→ 船便(約2週)→ 国内検品・販売開始
- 合計 約3〜4ヶ月

## 8. 主要リスク

- **IKEA側の仕様変更・廃番**: RUDSTAは定番だが恒久保証はない。→ 棚板は汎用寸法違いを追加しやすいレーザーカット(金型レス)とし、ライト/ファンは汎用品として他キャビネットにも展開可能な設計に。
- **高湿度環境での故障クレーム**: 防湿仕様の受入試験(40℃/90%RH 240h)を量産条件に含める。PL保険加入必須。
- **商標**: 商品名にIKEA/RUDSTAは使用不可。適合表記のルールは `COMPLIANCE.md` 参照。
- **模倣**: 意匠の独自性は限定的。先行者利益(レビュー蓄積)とキット完成度・日本語サポートで守る。
