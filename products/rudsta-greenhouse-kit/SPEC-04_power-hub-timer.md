# SPEC-04 電源系(GCK-HUB 電源ハブ / GCK-PSU24 ACアダプター)

## 1. システム構成(設計の要)

AC100Vに接続されるのは**PSE(菱形)認証済みACアダプター1個のみ**。
庫内・庫外の機器はすべてDC24V/5Vで動作させ、電気用品安全法の対象品目を最小化する。

```
壁コンセント AC100V
   │
[GCK-PSU24] DC24V/2.5A ACアダプター ← 唯一のPSE対象品(特定電気用品「直流電源装置」・菱形PSE)
   │ DC24V
[GCK-HUB] 電源ハブ(DC入力のためPSE対象外)
   ├─ LED出力×2(DC24V・24hタイマー制御)──→ LEDバー(デイジーチェーン可)
   └─ USB-A×2(DC5V/合計2A・常時ON)──→ 循環ファン、(将来オプション)
```

## 2. GCK-PSU24 ACアダプター(認証済み既製品から選定)

| 項目 | 仕様 |
|---|---|
| 入力 | AC100-240V 50/60Hz(日本仕様プラグ A型・2ピン) |
| 出力 | DC24V 2.5A(60W)、5.5×2.1mmプラグ、センタープラス |
| ケーブル長 | AC側一体型(壁刺し型不可・据置型)、DC側1.5m |
| 認証 | **PSE菱形(特定電気用品・直流電源装置)取得済みモデルであること。**証明書・登録検査機関の適合性検査証明の写しを提出必須 |
| 表示 | 菱形PSEマーク、定格、**当社(届出事業者)名の表示**(輸入者表示。銘板データは当社支給) |
| 保護 | OVP/OCP/SCP、効率DoE VI相当 |
| 環境 | 動作0〜40℃/〜90%RH、UL94 V-0筐体 |

## 3. GCK-HUB 電源ハブ(タイマー内蔵・専用OEM)

### 3.1 寸法・構造

| 項目 | 仕様 |
|---|---|
| 外形 | 110 × 70 × 26 mm(±1mm) |
| 筐体 | ABS(UL94 V-0)、艶消し黒 |
| 取付 | 背面マグネット+壁掛け穴。**庫外設置が原則**(取説で指示) |
| 質量 | ≤150 g |

### 3.2 電気仕様

| 項目 | 仕様 |
|---|---|
| 入力 | DC24V(5.5×2.1mmジャック)、最大60W |
| LED出力 | DC24V×2口(5.5×2.1mm)、合計 ≤50W、タイマー連動ON/OFF |
| USB出力 | USB-A×2、DC5V 合計2A(降圧DC-DC、効率≥90%)、常時ON |
| 保護 | 各出力に過電流保護、入力逆接続保護 |
| 待機電力 | ≤0.5W(LED出力OFF時) |

### 3.3 タイマー機能

| 項目 | 仕様 |
|---|---|
| 方式 | デジタル24hタイマー(1分単位)、ボタン3個+小型LCD |
| プログラム | ON/OFF各1点(例: 7:00点灯〜19:00消灯)。デフォルトは12h ON |
| 停電補償 | 内蔵電池またはスーパーキャパシタで時刻保持 ≥48h |
| 手動 | タイマー無効化(常時ON/常時OFF)切替 |

### 3.4 信頼性

- 40℃/90%RH・240h通電 → 機能異常なきこと(庫外設置前提だが多湿部屋を想定)
- 温度上昇: 全負荷時ケース表面 ≤55℃
- RoHS試験報告書提出

## 4. GCK-EXT DC延長ケーブル

- 5.5×2.1mmオス-メス、1.0m、22AWG以上、黒。UL758相当ワイヤ。

## 5. 検査・品質

- ハブ全数: 通電・タイマー動作・全ポート出力電圧検査
- AQL Major 2.5 / Minor 4.0
- アダプターはロットごとにPSE表示・銘板の目視全数(輸入者側の自主検査記録として保管 — `COMPLIANCE.md`参照)

## 6. 取説記載必須事項(安全)

- アダプター・ハブは庫内(高湿部)に設置しないこと
- ケーブルは一度下方にたるませてから引き込む(水滴伝い防止のドリップループ)
- タコ足配線・濡れた手での抜き差し禁止
