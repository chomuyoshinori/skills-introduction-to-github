# VERIFICATION — 実機実測チェックリストとFAI(初品検査)手順

★要実測の寸法をすべて確定させるまで、SPEC-03(棚板)・GCK-TRAY(トレイ)・LEDバー全長の**発注禁止**。
RUDSTAワイド/トール各1台を購入し、以下を実測して本書に記録 → 各SPECの暫定値を更新する。

### 1.4 環境ベースライン(空運転・製品開発用データ)

- 温湿度ロガーを庫内に設置し、シールテープ施工前/後 × ライト点灯12h/日で各72h記録。
- 記録項目: 庫内温度(最高/最低)、庫内湿度、室温との差。
- 判定目安: ライト点灯時の庫内温度が室温+5℃以内、湿度はシール後に植物なしで室内+10〜15%程度。
  (先行事例では植物投入後に約27℃/80%RHで安定した報告あり)

## 2. サンプル承認(各SPECの環境試験に加えて)

1. **実機適合**: 全部品を実機に取付け、(a)無加工で取付くこと (b)扉が正常に閉まること (c)棚板がガタなく載ること
2. **システム通電72h**: フル構成(ライト2/3本+ファン+ハブ)で72h連続運転 → 発熱・タイマー動作・電圧降下確認
3. **PPFD実測**: 各棚面9点でPPFDマッピング → SPEC-01の性能確認+取説の「棚別おすすめ植物」データ作成

## 3. FAI(量産初品検査)

- 量産ロット先頭から各品目n=5を抜き取り、全寸法・全性能項目を測定した検査成績書(FAIレポート)をサプライヤーに提出させる。
- FAI合格を量産続行の条件とする(発注書・PIにその旨を明記)。
- 以後のロットは AQL Major 2.5 / Minor 4.0 で第三者検品(または自社検品)。

## 4. 出荷前検品(中国側・推奨)

- 検品会社によるプレシップメント検査(PSI): 数量・外観・機能通電・梱包落下・表示(PSE銘板含む)。
- 特にACアダプターの**菱形PSEマークと届出事業者名表示**は全ロット必須確認項目。
