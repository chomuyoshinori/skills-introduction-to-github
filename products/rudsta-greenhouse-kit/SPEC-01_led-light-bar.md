# SPEC-01 植物育成LEDバーライト(GCK-LED690 / GCK-LED330)

## 1. 概要

RUDSTA庫内の各棚上面にマグネットで取り付けるフルスペクトラム育成ライト。
高湿度環境(〜95%RH)での常用を前提とする。2サイズ共通設計で長さのみ変更。

## 2. 寸法

| 項目 | GCK-LED690 | GCK-LED330 | 公差 |
|---|---|---|---|
| 全長(コネクタ除く) | 690 mm | 330 mm | ±2 mm |
| 断面(W×H) | 30 × 16 mm | 同左 | ±0.5 mm |
| 質量 | ≤450 g | ≤250 g | — |

- 690mmはワイド内寸幅(実測前提 約760mm ★要実測)に対しコネクタ+曲げ半径の逃げ70mmを確保する設計。
  **実測内寸確定後、全長は「内寸幅 −70mm」を上限に最終確定する。**
- 330mmはトール内寸幅(実測前提 約380mm ★要実測)−50mmを上限に最終確定。

## 3. 構造・材料

| 部位 | 仕様 |
|---|---|
| ボディ | アルミ押出 6063-T5、アルマイト艶消し黒 |
| カバー | PC乳白拡散カバー(UVカットグレード)、防滴パッキン付き |
| 端部キャップ | ABS(UL94 V-0)+シリコンシール |
| 実装基板 | アルミ基板、**コンフォーマルコーティング必須**(アクリル系以上) |
| 取付 | ボディ背面にネオジム磁石内蔵×3点(690mm)/×2点(330mm)、1点あたり垂直保持力 ≥1.5 kgf。落下防止用の粘着補助パッド同梱 |
| 防塵防水 | **IP54以上**(IP65歓迎) |

## 4. 電気仕様

| 項目 | GCK-LED690 | GCK-LED330 |
|---|---|---|
| 入力 | DC24V(許容21.6〜26.4V) | 同左 |
| 消費電力 | 20W ±10% | 10W ±10% |
| コネクタ | DC5.5×2.1mm(メス側リード0.3m)、直列連結(デイジーチェーン)用出力ポート付き | 同左 |
| 保護 | 逆接続保護、過電流保護 | 同左 |
| フリッカー | ちらつきなし(定電流駆動、脈流率<5%) | 同左 |

## 5. 光学性能(受入検査対象)

| 項目 | GCK-LED690 | GCK-LED330 |
|---|---|---|
| スペクトル | フルスペクトラム: 白色4000K(CRI Ra≥90)ベース + 660nm赤色補強。青400-499nm:15〜25%、赤600-700nm:35〜45%(PPF比) |
| PPF(光合成光量子束) | ≥36 µmol/s | ≥18 µmol/s |
| 効率 | ≥1.8 µmol/J | ≥1.8 µmol/J |
| PPFD(直下300mm・中心) | ≥120 µmol/m²/s | ≥100 µmol/m²/s |
| 配光 | 120°拡散。バー直下±15cmでPPFD均斉度 ≥0.6 |
| 見た目の色 | 自然な白(インテリア用途のため、ピンク色に見えるブループル比率は不可) |
| 寿命 | L70 ≥25,000時間 |

設計根拠: 対象植物のPPFD要求はシダ/カラテア40〜80、アロイド類80〜150、モンステラ/ホヤ150〜350 µmol/m²/s。棚間距離(約350〜400mm)でこのレンジをカバーする。

## 6. 環境・信頼性試験(サンプル承認条件)

1. 高温高湿連続点灯: 40℃/90%RH・240h → 点灯異常・結露浸入・腐食なきこと
2. 温度上昇: 25℃環境で連続点灯時、カバー表面 ≤60℃、ボディ ≤70℃
3. 落下: 梱包状態で80cm×6面落下 → 機能・外観異常なきこと
4. 磁石保持: 垂直鋼板上で自重の3倍荷重・24h → 滑落なきこと
5. RoHS試験報告書提出

## 7. 検査・品質

- 量産検査: AQL Major 2.5 / Minor 4.0(ANSI/ASQ Z1.4 Level II)
- 全数: 点灯検査。抜取: PPF測定(ロットあたりn=5、積分球またはPPFDマッピング)
- 保証: 対メーカー18ヶ月(販売保証12ヶ月+流通在庫6ヶ月)
