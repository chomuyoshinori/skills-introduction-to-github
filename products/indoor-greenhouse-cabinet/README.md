# 室内温室キャビネット「(仮称)グロウキャビネット」商品企画書 v2

RUDSTA改造キット企画(`products/rudsta-greenhouse-kit/`)を発展させ、
**キャビネット本体から自社設計して付属品込みで販売する**完成品温室。中国OEM(家具工場+電装工場の2系統)で製造・輸入する。

設計の原器はオーナー自作のDIY温室(IKEAコレクションケース改造・Instagram掲載機)。
DIYで判明した既製ケースの不満点を製品仕様で解消することが本製品の存在意義。

## 1. DIYで判明した課題 → 製品での解決(差別化の核)

| 既製ケース(RUDSTA等)の課題 | 本製品の解決策 |
|---|---|
| **配線を通す穴がない**(扉の隙間から出すしかない) | 天井・背面に**グロメット付き配線ポートを標準装備**。穴は機器の真上に配置し庫内で這わせない(SPEC-00 §5、SPEC-06) |
| **ライトのACアダプターの置き場がない**(裏にぶら下げるか床に転がす) | 天井上部の**機器収納ベイ+マグネット着脱式の電源ボックス**。箱ごと引き抜いて机上でメンテできる(SPEC-00 §6、SPEC-06 §5) |
| 棚板が空間を分断し、大型株・着生板が置けない | **棚なしの一室空間**。床面ワンフロア+壁面活用の設計 |
| 壁面の活用手段が乏しい | 背面フルスチール(マグネット吸着)+**マグネット小棚×2標準付属**(SPEC-03)+側面ワイヤーグリッド(着生板・ビカクシダ掛け) |
| 湿度は保てるが結露・水に弱い | 底面は防水パン構造+抜き差しできるPPトレイ、扉はEPDMガスケット標準 |
| 温度が上がりすぎたときの逃げがない | 上部に開閉式ベント×2(手動スライド) |

## 2. 商品コンセプト

- **ターゲット**: アロイド・ビカクシダ・ジュエルオーキッド等の高湿度系植物の愛好家(DIY温室勢がそのまま顧客像)。
- **一言**: 「配線・電源・湿度の"あと工夫"が全部済んでいる、そのまま使える植物温室」。
- **意匠**: 艶消し黒スチール+ガラス。生体ケージではなくインテリア家具の見た目を守る。

## 5. 設計方針(共通)

1. 電気系は前企画を踏襲: **AC系はPSE菱形認証済みアダプター1個のみ、庫内はすべてDC**。
   電装の固定は**すべてマグネット着脱式**(フック磁石吊り・電源ボックス・レースウェイ、`SPEC-06`)でネジ・粘着を使わない。
2. 庫内は常時RH70〜95%前提。スチールは全て粉体塗装+塩水噴霧240h、電装は防湿仕様。
3. 工具最小のKD(ノックダウン)組立、2人×40分以内。ガラスは全て強化ガラス。
4. 意匠統一: 艶消し黒(RAL9005近似)。
5. 拡張前提: 背面・天井がスチールなので、ユーザーがマグネットで自由に機器・小物を追加できる。
