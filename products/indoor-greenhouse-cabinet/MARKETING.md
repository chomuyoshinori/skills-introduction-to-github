# MARKETING — 競合分析・SWOT・ターゲット・訴求メッセージ

営業資料・クラファンページ・ECページ制作のための情報整理。価格・競合情報は2026年7月時点の調査値(※印は要再確認)。

## 1. 市場背景

- コロナ以降定着した観葉植物ブームの中で、アロイド(アンスリウム・アロカシア等)・ビカクシダ・ジュエルオーキッドなど**高湿度系の"コレクション株"市場**が拡大。1株数千〜数万円の株を複数持つ層が厚い。
- この層の共通課題は「日本の室内環境(エアコンの乾燥・冬の低温)で高湿度系を維持できない」。
- 解決策として海外発の「IKEA Greenhouse Cabinet」(ガラスキャビネットDIY改造)文化が日本にも上陸し、InstagramやYouTubeに事例が蓄積。ただし**日本で"完成品"を売るプレイヤーはほぼ不在**で、いまだに「みんなIKEAで自作している」のが実態(海外メディアPLNTS.comも「大半はIKEAのMilsbo/Rudsta/Detolfで自作」と総括)。
- → 「自作の面倒と失敗リスクをお金で解決したい層」が取り残されている = 本製品の市場仮説。

### 2.2 ポジショニング(2軸)

```
                 インテリア性 高
                      │
        (空白地帯)     │   ★本製品
     海外完成品⑤      │   (家具見え×電装込み完成品)
                      │      ①IKEA DIY(上手くやれば)
 完成度 低 ──────────┼────────── 完成度 高(電装・湿度設計込み)
 (自分で構成)         │
        ④ビニール温室  │      ⑥水耕栽培機(用途違い)
        ②園芸温室      │      ③パルダリウムケージ(小型)
                      │
                 インテリア性 低
```

**結論: 「家具として飾れる × 電装・配線・湿度が設計済み × 大型一室空間」の象限は国内空白。**
最も怖い競合は既製品ではなく「①DIYの楽しさ」と「ユーザーの現状維持(何も買わない)」。

## 3. SWOT

| | プラス | マイナス |
|---|---|---|
| **内部** | **S(強み)** ①DIYの不満を仕様で潰した唯一の完成品(配線ポート・機器ベイ・棚なし一室・マグネット壁面) ②開発者自身がDIY実践者=説得力ある開発ストーリーとSNS資産 ③電装込みでも競合構成より手間ゼロ ④増設アクセサリーで継続売上(小棚・ライト・ファン) | **W(弱み)** ①フルセット¥59,800はDIY総額(3〜4万)より高い ②大型・重量物で送料/返品/破損コストが重い ③無名ブランド・実績ゼロ ④加温機能なし(冬の保温はヒーター別途=②園芸温室に劣る点) ⑤生体(カエル等)非対応を明示する必要 |
| **外部** | **O(機会)** ①国内完成品市場が空白 ②高額株の普及で「株を守る投資」の説得が容易 ③SNSで温室内装を見せる文化(ネオン等)が追い風 ④B2B(植物ショップ・カフェ・オフィス)のディスプレイ需要 | **T(脅威)** ①中国工場が同等品を直販するコピーリスク ②IKEAが公式に温室対応した場合 ③植物ブーム退潮 ④電気代・物価上昇による高額趣味の節約 |

**弱み①への反論設計(FAQ用)**: DIY総額3〜4万円+パーツ選定と工作に数日+失敗リスク(カビ・結露故障・棚が使えない)に対し、+2万円で「設計済み・保証付き・組立40分」。1株1万円の株を2つ守れば元が取れる、という換算話法を使う。

## 4. ターゲット(ペルソナ)

### メイン: ①コレクター深化層(最優先)
- 30〜45歳、都市部集合住宅、植物歴2年以上。アロイド/ビカクシダ/ジュエルオーキッドに月1〜3万円。
- 痛み: 「エアコンで葉先が枯れる」「冬に高い株を枯らした」「加湿器を回すと部屋がカビる」。
- 購買動機: **株を守る保険**。価格感度は低め、失敗回避が最優先。
- 刺さる訴求: 湿度の実測データ、枯らした後悔の想起、「専用環境」という言葉。

### サブ1: ②インテリア文脈層
- 25〜40歳、「植物のある暮らし」をSNSに投稿。温室の中を飾る(ネオンサイン・フィギュア等)ことも楽しむ。※オーナーDIY機のスタイルはまさにこれ
- 痛み: DIYの配線がダサい・生活感が出る。
- 刺さる訴求: 「光る家具」としてのビジュアル、配線が見えない設計、夜のリビングでの見え方。

### サブ2: ③ステップアップ層(入門〜中級)
- 植物歴1年前後。ビニール温室や卓上ケースで限界を感じている。
- 痛み: 何を買い足せばいいか分からない。電気が怖い。
- 刺さる訴求: 「これ1箱で完結」「工具は付属の六角レンチだけ」「タイマー設定済み」。

### サブ3: ④寒冷地・冬越し断念層
- 北海道・東北・日本海側など。「冬に全滅するから」と熱帯植物(アロイド・ビカク・塊根の実生など)を最初から諦めていた層。
- 痛み: 夜間の室温1桁・窓際の冷気・暖房オフ時間帯。温室=大掛かりで高い、という思い込み。
- 刺さる訴求: **点灯中はLEDパネルの排熱で庫内が室温+3〜5℃**+密閉が冷気・乾燥風を遮断。
  夜間の冷え込みには**背面P3ポートからパネルヒーターを無加工で増設**できる(サーモ管理)。
- ⚠️ 訴求の正直ライン: 「LEDだけで真冬の無暖房部屋でも越冬できる」とは言わない(消灯中は室温に漸近する)。
  「日中はライトの熱、夜はヒーター増設」のセットで語る。寒冷地セット(ヒーター+サーモ)のオプションSKU候補。

### サブ4(B2B): 植物ショップ・カフェ・オフィス
- 高額株のディスプレイ兼保管。什器として即戦力。掛率・保守対応が論点。

## 5. 謳い文句(コピー案)

### タグライン(メイン候補)
1. **「配線も、電源も、湿度も。ぜんぶ設計済みの室内温室。」**(機能総括・EC向け)
2. **「もう、飾り棚を改造しなくていい。」**(DIY文化への挑戦状。※他社名は出さない)
3. **「リビングに、熱帯をひと部屋。」**(情緒・ブランド向け)

### サブコピー(訴求別)
- 湿度: 「エアコンの効いた部屋で、湿度80%の環境をつくる。」
- 保険換算: 「その一株を枯らす前に。温室は"株を守る保険"です。」
- 機器ベイ: 「アダプターの置き場所で、もう悩まない。天井の中に、ぜんぶ隠れる。」
- 配線ポート: 「配線穴、最初から開いています。」
- 一室空間: 「棚は、つけませんでした。大きく育てるための余白です。」
- マグネット小棚: 「壁に、好きな高さで、小さな株を。」
- 持ち込み互換: 「手持ちのライトもファンも、そのまま貼れる。」(背面・天井がスチールで、どこでも磁石が効く。DIY経験者の乗り換え障壁を下げる)
- 寒冷地: 「北国でも、熱帯は諦めなくていい。」(点灯中は室温+3〜5℃+ヒーター増設ポート標準)
- 水やり動線: 「鉢ごと置いて、そのまま水やり。」(棚は水抜き底で水を溜めず、床の防水パン+引き出せるトレイが受ける)
- 組立: 「工具は付属の六角レンチひとつ。40分で熱帯が立ち上がる。」
- ランニングコスト: 「電気代は1日約20円。」(LED50W×12h+ファン常時 ≒ 月約21kWh・約650円 @31円/kWh)
- SNSハッシュタグ: #温室のある暮らし #室内温室 #グロウキャビネット

### 開発ストーリー(クラファン・LP冒頭用の骨子)
「市販のガラスキャビネットを自分で改造して温室にした。湿度は保てた。植物はよく育った。
でも――配線を通す穴がない。アダプターの置き場がない。棚が大きな株の邪魔をする。
"最初からそう作られた温室"が欲しかったので、自分たちで作ることにした。」
(→ DIY機の写真・温湿度計25℃/67%の実測画面を証拠として掲載)

## 6. チャネルと展開順序(提案)

1. **クラウドファンディング(Makuake/GREEN FUNDING)で先行販売**: 需要検証+初回ロット資金+「応援購入」文脈は高単価と相性が良い。目標100台。
2. 自社EC(Shopify)+ Instagram/YouTube: オーナーのDIY投稿実績をそのまま公式アカウントの種にする。植物系YouTuberへの貸与レビュー3〜5名。
3. Amazon/楽天は2次展開(送料・返品コストを織り込んでから)。
4. B2Bは展示会(国際ガーデンEXPO等)とショップへの直営業。
