# SOURCING — 中国OEM調達の実務ガイド(グロウキャビネット向け)

社内用チェックリスト。RFQ〜量産〜輸入までの留意点を本製品の構成に即して整理する。

## 0. 製造難易度の評価: 「普通に作れる」

| 部品 | 使う工程 | 難易度 | 型費 |
|---|---|---|---|
| キャビネット本体 | レーザーカット+ベンダー曲げ+溶接+粉体塗装+強化ガラス框組 | **低**(ディスプレイケース・爬虫類ケージ・グロウテントで確立した工程) | ほぼ不要(治具のみ) |
| ハーフトレイ | PP真空成形 | 低 | 数万〜十数万円 |
| EBOX | ABS成形 | 低〜中 | **射出なら型50〜100万円** → v1は真空成形(型費数万)or 既製エンクロージャ改造を推奨 |
| LED・ファン・小棚・電源 | 既製ODM(B/C区分) | 低 | 不要 |

- 特殊なのは工程ではなく**要求水準**: 常時RH70〜95%の耐湿・防錆、磁性面の塗膜管理、強化ガラス証明。
  工場は「温室に使われる」ことを知らないので、**試験条件を仕様書で数値指定**する(済み: 各SPEC)。
- 産地目安: 板金+ガラス家具=佛山・青島クラスタ、電装=深圳・中山、既製ラック=寧波・金華。

## 1. サプライヤー選定

- [ ] **工場と商社を見分ける**: 営業執照(事業ライセンス)の経営範囲を確認。「なんでも作れる」は商社。
      本件は**家具系と電装系で最低2社に分ける**(1社に丸投げするとマージン二重取り+品質責任が曖昧に)
- [ ] Alibabaなら Verified Supplier+取引実績。最終候補は**第三者工場審査**($300〜500、QIMA/V-Trust等)か
      ビデオ工場ツアーで実在・設備・稼働を確認
- [ ] 同種品(ガラスキャビネット/爬虫類ケージ/グロウテント)の**製造実績があるか**を最初に聞く
- [ ] 相見積もりは3社以上。極端に安い1社は材料すり替えの前兆と考える

## 2. 見積り・仕様の固定(いちばん事故が起きる場所)

- [ ] RFQには図面(`drawings.html`→PDF化)+SPEC+**数値指定**を添付: t0.8、N38、IP54、強化ガラス、
      塩水噴霧240h、AQL 2.5/4.0。「良い材料を使う」等の形容詞は書かない
- [ ] **典型的なすり替えポイント**を見積り時に名指しで確認:
      板厚(0.8→0.6)、磁石グレード(N38→N35)、強化ガラス→生ガラス、粉体塗装→焼付なし吹付、
      ボールベアリング→スリーブ、コンフォーマルコーティング省略
- [ ] 材料証明の提出を条件化: ミルシート、強化ガラス破砕試験、RoHS、PSE証明(アダプター)
- [ ] 見積り条件: FOB(港指定)、MOQ、量産リードタイム、**サンプル費と量産時の返金条件**、支払条件を書面で

## 3. 契約・支払い

- [ ] **NNN契約**(秘密保持+不使用+迂回禁止)を締結。英文NDAは中国では実効性が薄い——
      **中国語・中国法準拠・中国裁判管轄**のNNNにする(雛形は中国系法律事務所で数万円)
- [ ] PI(発注書)に明記: 仕様書の版数(例: SPEC v0.7)、**FAI合格を量産開始条件**、AQL、納期、
      遅延ペナルティ、**金型・治具の所有権は当社**(型費を払ったら所有権と持出権を書面化)
- [ ] 支払い: **T/T 30/70**(前金30%、残70%は出荷前検品合格後)。初回はAlibaba Trade Assurance併用も可
- [ ] 「モールドは無料にする代わりMOQ引き上げ」の提案は型の人質化リスク——型費は払って所有する

## 4. 品質管理(遠隔で品質を担保する仕組み)

- [ ] サンプル承認 → (量産前)PPサンプル → **FAI(初品検査)** → 量産、の4段階を踏む(`VERIFICATION.md`)
- [ ] **第三者検品(PSI)を全ロット必須**($300前後/人日): 数量・外観・寸法抜取・通電・磁力実測・
      板厚実測・梱包落下・PSE銘板。検品リストは当社が支給(SPECの受入条件をそのまま使う)
- [ ] 初回ロットは中間検品(DUPRO)も追加(塗装前・組立前に潰す)
- [ ] 高湿試験(40℃/90%RH)は工場任せにせず**試験成績書+自社で試作機の実運用1ヶ月**の二重化
- [ ] 不良の定義を写真つきで共有(限度見本)。「キズ」の基準は日中で大きくズレる

## 5. 知財・横流し対策

- [ ] NNN+型所有権(上記)が基本
- [ ] **差別化要素を1社に集中させない**: 本体図面一式は家具工場のみ、電装仕様は電装側のみ、
      ブランドロゴ・印刷データは発注の最終段階で支給
- [ ] 工場の自社販売(同型品のAlibaba出品)は完全には防げない前提で、
      日本側の意匠出願(庫内EBOX+四隅グロメットポート構成)とブランド・レビュー蓄積で守る(`COMPLIANCE.md` §4)

## 6. 物流・輸入

- [ ] インコタームズは**FOB**+日本側フォワーダー指名が初心者向け(EXWは中国内陸コスト管理が難しく、
      CIFは工場側の安い保険・船社で事故時に泣く)
- [ ] ガラス輸送: ISTA-2A梱包試験合格を出荷条件に。**コンテナ内の積付指示書**(平積み段数・向き)を支給
- [ ] 破損引当: 初回ロットはガラス框・グロメット等の補修部品5%を同梱輸入(`BOM.md`)
- [ ] 輸入時: PSEアダプターの菱形表示+届出事業者名を通関前に写真確認。インボイスはセット品の
      関税分類(GRI3)を通関士と事前に決めて明細を切る
- [ ] リードタイムに**春節(1〜2月・実質1ヶ月停止)と国慶節(10月頭)**を織り込む。初回発注は春節を跨がない計画に

## 7. コミュニケーションの実務

- [ ] 窓口はWeChat(メールは読まれない)。ただし**合意事項は必ずメール/PIに転記**して証跡化
- [ ] 図面・仕様は英語+主要項目のみ中国語併記が理想。数値と図で語り、形容詞を避ける
- [ ] 担当者(業務員)の離職が多い——仕様書・限度見本を工場側にも正式保管させ、属人化を防ぐ
- [ ] 「можно/没问题(できます)」は「聞いた」程度の意味。できるかどうかは**サンプルだけが証拠**

## 8. 初回発注のマイルストーン(推奨)

1. RFQ 3〜5社 → 工場審査 → 2社に絞る(家具1・電装1)
2. NNN締結 → サンプル発注(有償・$200〜500/式)
3. サンプル実機評価(`VERIFICATION.md` §2)+DIY原器と並走
4. PI発行(FAI条件付き)→ 前金30% → 量産 → DUPRO → PSI → 残金70% → 出荷
5. 国内受入検品 → Amazon販売開始(出品者出荷・神田氏物流)

> 総括: この製品で「作れない」工程は一つもない。失敗パターンは技術ではなく
> **①仕様を数値で固定しなかった ②検品を省いた ③春節を忘れた ④型と知財を工場に握られた** の4つ。
> 本ガイドのチェックボックスはすべてその予防策である。
