# SPEC-05 付属品(温湿度計・フック・クリップ・トレイ・マット・メッシュパネル)

前企画 `products/rudsta-greenhouse-kit/SPEC-05` から流用。変更点のみ記す。
すきまテープ(GCK-SEAL)は**廃止** — 本体扉にEPDMガスケットを標準内蔵したため不要。

## 1. GRC-HYGRO デジタル温湿度計(前GCK-HYGROと同一仕様)

- LCD・**無線なし**(技適回避)、温度-10〜60℃±1℃/湿度10〜99%RH±5%RH、最高最低メモリ。
- CR2032×1(個装・絶縁タブ付き)、背面マグネット。黒、約60×60×20mm、高湿環境1年保証。
- 取付想定: 背面パネル中段(DIY機の実績位置)。

## 2. GRC-MAG マグネットフック(×6・前GCK-MAGと同一仕様)

- ネオジムN35以上φ25、フルラバー被覆黒、垂直保持≥2.5kgf。
- 用途: 側面グリッドと併用した着生板の吊り、霧吹き等の小物掛け、ケーブル取り回し。

## 3. GRC-CLIP ケーブルクリップ(×10・前GCK-CLIPと同一仕様)

- ナイロン+VHB相当粘着20×20mm、対応径φ3〜6mm、黒。

## 4. GRC-TRAY 底面ガーデニングトレイ(ハーフ2分割・標準付属)

**フル1枚からハーフ2枚に設計変更**。鉢を満載したフルトレイは重くて引き出せないため、
半分ずつ引き出して水捨て・丸洗いできる2分割とする(片側だけの掃除・レイアウト替えも可能)。

| 項目 | 仕様 |
|---|---|
| 外形 | **360 × 315 × 25 mm × 2枚**(±2mm)— 防水パン内寸740×320に2枚+中央間隙 |
| 材質 | PP 艶消し黒、底面リブ、水容量 ≥1.0L/枚 |
| 構造 | 前縁に指掛かり一体形状。取説表示: 鉢を載せたままの引き出しは2〜3鉢まで |
| 成形 | 真空成形(フル1枚案より型が小さく型費減)。増設・補修の単品SKUにも展開 |

- 本体の防水パン(スチール・立上り30mm)の**内側に載せる二重防水**。日常の水受けはトレイ、万一の溢れはパンで受ける。

## 5. GRC-DRAIN 洗える水切りマット(トレイ内敷き・標準付属)

鉢底を水たまりから浮かせて根腐れ・ヌメリを防ぐ。**珪藻土マットは不採用** —
常時RH70〜90%の庫内では乾燥再生できずに飽和し、カビの温床になる(割れ・粉化の衛生問題もある)。
高湿でも腐らず丸洗いできるPVCコイル構造を採用する。

| 項目 | 仕様 |
|---|---|
| 形式 | PVCコイル(ループ)マット、抗菌剤練込み、黒 |
| 寸法 | 345 × 295 × 厚8mm × 2枚(ハーフトレイ内寸に整合・カット済み) |
| 手入れ | 取り出してシャワー丸洗い可。塩素系漂白剤の希釈液での洗浄に耐えること |
| 耐荷重 | 鉢直置きで凹み残りなきこと(60kg/m²・24h)。水はコイル間を抜けてトレイに落ちる |

## 6. GRC-MESH ビカクシダ用マグネットメッシュパネル(単品オプションSKU)

板付けビカクシダ・着生板を背面の「主役の位置」に飾るパネル。
**フルセットには含めず単品オプション**(ビカク層は厚いが全ユーザーではない。
クラファンでは「ビカクセット」リターンの差別化アイテムに使う)。

| 項目 | 仕様 |
|---|---|
| 外形 | W350 × H450 mm、ワイヤーφ3・ピッチ25mm、粉体塗装黒 |
| 取付 | 背面マグネット8点+全面ゴムシート。**スタンドオフ20mm**(パネル裏に通気層を作り、水苔の乾きと背面の結露を防ぐ) |
| 耐荷重 | 3.0kg(湿潤の板付け1〜2枚)。垂直ずり保持 ≥9kgf(定格3倍)、SPEC-03と同一試験条件 |
| 付属 | S字フック×2。麻紐掛けを想定し全周バリなし |
| 配置 | 推奨ゾーン Z=300〜800(`SPEC-06` §3 ドットグリッドに整列)。小棚(W350)と同幅で入れ替え運用できる |
