# SPEC-05 付属品(温湿度計・フック・クリップ・トレイ・メッシュパネル)

前企画 `products/rudsta-greenhouse-kit/SPEC-05` から流用。変更点のみ記す。
すきまテープ(GCK-SEAL)は**廃止** — 本体扉にEPDMガスケットを標準内蔵したため不要。

## 1. GRC-HYGRO デジタル温湿度計(前GCK-HYGROと同一仕様)

- LCD・**無線なし**(技適回避)、温度-10〜60℃±1℃/湿度10〜99%RH±5%RH、最高最低メモリ。
- CR2032×1(個装・絶縁タブ付き)、背面マグネット。黒、約60×60×20mm、高湿環境1年保証。
- 取付想定: 背面パネル中段(DIY機の実績位置)。

## 2. GRC-MAG マグネットフック(×6・前GCK-MAGと同一仕様)

- ネオジムN35以上φ25、フルラバー被覆黒、垂直保持≥2.5kgf。
- 用途: 側面グリッドと併用した着生板の吊り、霧吹き等の小物掛け、ケーブル取り回し。

## 3. GRC-CLIP ケーブルクリップ(×10・前GCK-CLIPと同一仕様)

- ナイロン+VHB相当粘着20×20mm、対応径φ3〜6mm、黒。

## 4. GRC-TRAY 底面ガーデニングトレイ(ハーフ2分割・**波形底**・標準付属)

**フル1枚からハーフ2枚に設計変更**(v0.3)。**v0.8.1(オーナー指示): 底面を波形(コルゲート)一体成形に変更し、
剛性を「植物を載せたまま持ち運べる」レベルに引き上げ**。焼肉プレートの脂落としと同じ原理で、
鉢は波の山に載り、水やりの余り水は波の谷に落ちて鉢底と分離される(水切りマット廃止・部品1点化)。

| 項目 | 仕様 |
|---|---|
| 外形 | **360 × 315 × H35 mm × 2枚**(±2mm)— 防水パン内寸740×320に2枚+中央間隙 |
| 底面 | **波形一体成形: 波ピッチ20×波高10mm**。波(谷)は前後方向に通し、前縁の**注ぎ口**へ緩勾配で導水。谷の貯水容量 ≥0.8L/枚 |
| 剛性(重要) | **満載8kg(鉢+水)を前縁の指掛かりで両手持ちして水平運搬できること: 中央たわみ≤10mm・白化/クラック/永久変形なきこと**。波形が構造リブを兼ね、全周フランジ折返しで補強 |
| 材質・成形 | **PP射出成形(タルク強化20%または肉厚2.5以上)** 艶消し黒。※真空成形(薄肉)は剛性不足のため不可 |
| 構造 | 前縁に指掛かり+注ぎ口一体形状。引き出してそのまま流しで水捨て・丸洗い |

- 本体の防水パン(スチール・立上り30mm)の**内側に載せる二重防水**。日常の水受けはトレイ、万一の溢れはパンで受ける。
- 射出金型費が発生(1型2キャビ想定)。増設・補修の単品SKU(¥1,280想定)で回収に寄与。

## 5. ~~GRC-DRAIN 洗える水切りマット~~ **廃止(v0.8.1)**

- トレイの波形底が「鉢底を水から浮かせる」機能を一体化したため不要。洗う部品もトレイ1つに減る。
- (参考・経緯)珪藻土マットは高湿庫内で乾燥再生できず不採用 → PVCコイルマット採用(v0.2)→ 波形底トレイに統合(v0.8.1)。
