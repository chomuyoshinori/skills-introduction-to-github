# SPEC-04 電源系(GRC-HUB 電源ハブ / GRC-PSU24 ACアダプター)

前企画 `products/rudsta-greenhouse-kit/SPEC-04` をベースに、本体の**機器収納ベイへの組込み**と
LEDパネル2枚(計50W)+ファン2基への給電に合わせて改訂。電気設計思想は同一:
**AC系はPSE菱形認証済みACアダプター1個のみ、下流はすべてDC**。

```
壁コンセント AC100V
   │ (キャビネット背面の配線ポートP2から機器ベイへ)
[GRC-PSU24] DC24V/3.0A(72W)ACアダプター ← 唯一のPSE対象品(特定電気用品「直流電源装置」・菱形)
   │
[GRC-HUB] 電源ハブ(機器ベイ内にマグネット固定・DC入力のためPSE対象外)
   ├─ LED出力×2(DC24V・24hタイマー制御)─ P1グロメット経由で庫内へ ─→ LEDパネル×2
   └─ USB-A×3(DC5V/合計2.4A・常時ON)─ 同上 ─→ 循環ファン×2 +予備1口
```

## 1. GRC-PSU24 ACアダプター(認証済み既製品から選定)

| 項目 | 仕様 |
|---|---|
| 入出力 | AC100-240V 50/60Hz(A型プラグ)→ DC24V 3.0A(72W)、5.5×2.1mmセンタープラス |
| ケーブル | 据置型、DC側1.5m |
| 認証 | **PSE菱形取得済みモデル必須**。証明書・適合性検査証明の写し提出。銘板に当社(届出事業者)名表示(データ支給) |
| 保護・環境 | OVP/OCP/SCP、動作0〜40℃/〜90%RH、UL94 V-0 |
| 熱設計 | 機器ベイ内(周囲最大50℃)で定格連続運転可能なこと(ディレーティング表提出) |

## 2. GRC-HUB 電源ハブ(専用OEM)

### 2.1 寸法・構造

| 項目 | 仕様 |
|---|---|
| 外形 | 110 × 70 × 26 mm(±1mm)、ABS(UL94 V-0)艶消し黒 |
| 取付 | 背面マグネット(機器ベイのマグネット座に固定)+ネジ穴 |
| 操作面 | 機器ベイの蓋を開けて操作。LCDと操作ボタンは上面配置 |

### 2.2 電気仕様

| 項目 | 仕様 |
|---|---|
| 入力 | DC24V(5.5×2.1mm)、最大72W |
| LED出力 | DC24V×2口、合計≤60W、タイマー連動 |
| USB出力 | USB-A×3、5V合計2.4A(降圧効率≥90%)、常時ON |
| 保護 | 各出力過電流、入力逆接続 |
| 待機電力 | ≤0.5W |

### 2.3 タイマー

- デジタル24h(1分単位)、ON/OFF各1点、デフォルト12h点灯。停電時刻保持≥48h。常時ON/OFF切替あり。

## 3. ケーブル計画(本体との整合)

- LEDパネルリード0.5m+延長1.0m×2本同梱 → ベイ内ハブからP1経由で天井面まで届くこと(経路長実測は試作時)。
- ファンはケーブル2.0m直結(SPEC-02)。
- 全ケーブルは黒、庫内露出部は貼付式クリップ(SPEC-05)で背面パネルに整線。

## 4. 信頼性・検査

- ベイ内想定 50℃/90%RH・240h通電 → 機能異常なきこと
- 全負荷時ケース表面 ≤60℃(ベイ内)
- 全数: 通電・タイマー・全ポート電圧。AQL Major 2.5 / Minor 4.0。RoHS報告書

## 5. 取説記載必須事項(安全)

- アダプター・ハブは必ず機器ベイ内に設置(庫内・水がかかる場所は不可)
- P2から入線する際はドリップループを作る
- ベイの通気スリットを塞がない
- 加湿器を庫内で使用しない
