# SPEC-04 電源系(GRC-HUB 電源ハブ / GRC-PSU24 ACアダプター)

前企画 `products/rudsta-greenhouse-kit/SPEC-04` をベースに、**庫内天井裏の防滴EBOXへの組込み(v0.6)**と
LEDパネル2枚(計50W)+ファン2基への給電に合わせて改訂。電気設計思想は同一:
**AC系はPSE菱形認証済みACアダプター1個のみ、下流はすべてDC**。

```
壁コンセント AC100V
   │ (ACコードはP2グロメット(φ40・背面右上、膜に切込み)を通す。AC系はこの1本だけ)
[GRC-PSU24] DC24V/3.0A(72W)ACアダプター ← 唯一のPSE対象品(特定電気用品「直流電源装置」・菱形)
   │ (防滴EBOX内・庫内天井裏 — v0.6)
[GRC-HUB] 電源ハブ(EBOX内に固定・DC入力のためPSE対象外)
   ├─ LED出力×2(DC24V・24hタイマー制御)─ 天井裏で直結 ─→ 吊りLEDパネル×2
   └─ USB-A×3(DC5V/合計2.4A・常時ON)──→ 循環ファン×2 +予備1口
```

## 1. GRC-PSU24 ACアダプター(認証済み既製品から選定)

| 項目 | 仕様 |
|---|---|
| 入出力 | AC100-240V 50/60Hz(A型プラグ)→ DC24V 3.0A(72W)、5.5×2.1mmセンタープラス |
| ケーブル | 据置型、**AC側コード2.0m**(天井裏EBOX→P2→床コンセントの必要長約1.8mに余裕。SPEC-06 §7.5)・DC側1.5m |
| 認証 | **PSE菱形取得済みモデル必須**。証明書・適合性検査証明の写し提出。銘板に当社(届出事業者)名表示(データ支給) |
| 保護・環境 | OVP/OCP/SCP、動作0〜40℃/〜90%RH、UL94 V-0 |
| 熱設計 | EBOX内(周囲最大50℃)で定格連続運転可能なこと(ディレーティング表提出) |

## 2. GRC-HUB 電源ハブ(専用OEM)

### 2.1 寸法・構造

| 項目 | 仕様 |
|---|---|
| 外形 | 110 × 70 × 26 mm(±1mm)、ABS(UL94 V-0)艶消し黒 |
| 取付 | EBOX内に面ファスナー固定(EBOXごとマグネット着脱、SPEC-06 §5) |
| 操作面 | 背面ポケットのカバーを外して操作。LCDと操作ボタンは前面(カバー側)配置 |

### 2.2 電気仕様

| 項目 | 仕様 |
|---|---|
| 入力 | DC24V(5.5×2.1mm)、最大72W |
| LED出力 | DC24V×2口、合計≤60W、タイマー連動 |
| USB出力 | USB-A×3、5V合計2.4A(降圧効率≥90%)、常時ON |
| 保護 | 各出力過電流、入力逆接続 |
| 待機電力 | ≤0.5W |

### 2.3 タイマー

- デジタル24h(1分単位)、ON/OFF各1点、デフォルト12h点灯。停電時刻保持≥48h。常時ON/OFF切替あり。

## 3. ケーブル計画(本体との整合)

- LEDパネルは**リード1.0m直結**(SPEC-01)。DC延長ケーブル(旧GRC-EXT)は**廃止** —
  P1穴の背面両角化+EBOX中央配置により不要(配線長バジェット: SPEC-06 §7.5)。
- ファンはケーブル2.0m直結(SPEC-02)。余長はベイ内で束線。
- 全ケーブルは黒、庫内露出部はレースウェイ(SPEC-06 §6)と貼付式クリップ(SPEC-05)で背面に整線。

## 4. 信頼性・検査

- 庫内相当(40℃/95%RH)・240h通電+**満載30日高湿通電**(SPEC-06 §8)→ 機能異常なきこと
- 全負荷時ケース表面 ≤60℃(EBOX内)
- 全数: 通電・タイマー・全ポート電圧。AQL Major 2.5 / Minor 4.0。RoHS報告書

## 5. 取説記載必須事項(安全)

- アダプター・ハブは必ず**防滴EBOX内**に収める(v0.6: EBOXごと天井裏に吊る)。**裸のアダプタ・電源タップの庫内直置きは厳禁**
- 各ケーブルはEBOXの下面切欠きから下向きに出す(ドリップループが自然に形成される)。ACコードはP2グロメット(φ40・膜に切込み)から庫外へ
- EBOXの下面開口を塞がない。異臭・誤動作時は直ちに電源を抜く(高湿環境使用のため取説強調)
- 加湿器を庫内で使用しない
