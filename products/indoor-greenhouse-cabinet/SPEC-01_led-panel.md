# SPEC-01 LEDパネルライト(GRC-LED)

## 0. 調達方針: 既製ODMベース(専用設計しない)

クワッドボード型育成パネルは中国に白ラベル(ODM)供給元が多数あり、**既製モデルをベースに
下記の必須改修のみ加える(調達区分B)**。専用金型・専用光学設計は行わない。
理由: ①本製品の差別化はキャビネット側にあり電装はコモディティ ②MOQが下がり初回ロット100台と整合
③市場実績のある既製品の方が初品リスクが低い ④故障対応が型番交換で済む。

**既製ベースへの必須改修(この5点だけ要求する)**
1. 上辺に吊り金具(Dリング)×2 ピッチ200mm(なければ後付けブラケットで可)
2. 入力をDC24V 5.5×2.1mmに統一(モデルにより12V/USBが多いため要確認。付属アダプター系は使わない)
3. 基板コンフォーマルコーティング(高湿対応)
4. スペクトル指定: 白4000Kベース+660nm(§4。ピンク見えの強い配色は不可)
5. ロゴ印字・黒筐体

以降の性能・試験要件は既製ベースでも**そのまま受入条件として適用**する。

## 1. 概要

天井スチールパネルにマグネットで取り付けるクワッドボード型のフルスペクトラムLEDパネル。
オーナーDIY機で採用しているタイプ(白+660nm赤の面光源パネル)を踏襲する。
棚のない一室空間で、天井から床面(照射距離 最大約0.9m)までをカバーする配光が要件。

## 2. 寸法・構造

| 項目 | 仕様 |
|---|---|
| 外形 | 280 × 280 × 35 mm(±2mm)、フルセットには2枚同梱 |
| 質量 | ≤900 g/枚 |
| ボディ | アルミ板金+放熱フィンレスの面放熱設計、艶消し黒 |
| 基板 | アルミ基板、**コンフォーマルコーティング必須**、LED素子むき出し不可(クリアコートまたは薄型カバー) |
| 取付 | **フック磁石吊り下げ式**: 上辺に吊り金具(Dリング)×2 ピッチ200mm。天井のフック磁石(GRC-HOOK32、垂直引張≥8kgf)+高さ調整ハンガー(GRC-HANG、調整50〜400mm)で水平吊り。位置・座標は`SPEC-06` §2 |
| 防湿 | IP54相当(上面からの結露滴下に耐えること) |

- **吊り高さ=照射距離の調整機構**を兼ねる(下げれば強光・上げれば弱光)。工具なしで着脱でき、メンテ時はフックから外すだけ。
- 落下防止ワイヤーテザー(天井フレーム掛け・カラビナ付き)は継続して必須。フック磁石との二重保持(PL対策)。

## 3. 電気仕様

| 項目 | 仕様 |
|---|---|
| 入力 | DC24V(許容21.6〜26.4V)、5.5×2.1mmコネクタ、**リード1.0m・パネル背面側端部から出し**(天井裏EBOXのハブへ直結するため。SPEC-06 §7.5の配線長バジェット準拠) |
| 消費電力 | 25W ±10%/枚 |
| 調光 | 3段階(100/60/30%)、本体側面スイッチ。将来ハブからのPWM制御に対応できる制御線ピン予約 |
| 保護 | 逆接続・過電流保護。フリッカーレス(脈流率<5%) |

## 4. 光学性能(受入検査対象)

| 項目 | 仕様 |
|---|---|
| スペクトル | 白4000K(CRI Ra≥90)+660nm赤。青400-499nm 15〜25%、赤600-700nm 35〜45%(PPF比) |
| PPF | ≥45 µmol/s/枚 |
| 効率 | ≥1.8 µmol/J |
| PPFD | 直下300mmで≥300、直下900mm(床面相当)で≥70 µmol/m²/s |
| 配光 | 120°。2枚を天井に並置した際、床面(760×330mm)のPPFD均斉度 ≥0.5 |
| 見た目 | 自然な白(ピンク見えの強い比率は不可。室内インテリア用途) |
| 寿命 | L70 ≥25,000h |

- 設計根拠: 床置きの大型株(モンステラ・ビカクシダ 150〜350 µmol/m²/s要求)は吊り下げ高さで調整、
  背面マグネット小棚(高さ自由)で小型株(40〜150)をライト近くに寄せられる構成。

## 5. 信頼性試験(サンプル承認条件)

1. 40℃/90%RH・240h連続点灯 → 異常なきこと
2. 表面温度: 25℃環境・100%出力でボディ ≤65℃
3. 吊り系: フック磁石1点あたり定格3倍(2.7kg)×24h+扉開閉衝撃100回で滑落なし。Dリング・ハンガーは自重5倍、テザー単体は自重10倍の静荷重に耐えること
4. RoHS報告書

## 6. 検査・表示

- 全数点灯・調光検査。抜取PPF測定(n=5/ロット)
- 本体印字: DC24V 25W、型番、ロット。PSE対象外(DC機器)
- AQL Major 2.5 / Minor 4.0
