## 1. 電気用品安全法(PSE)— 前企画と同じ構造

| 部品 | 区分 | 対応 |
|---|---|---|
| ACアダプター(GRC-PSU24) | 特定電気用品「直流電源装置」→ **菱形PSE必須** | 認証済み既製品を採用。証明書写し入手、銘板に当社名 |
| LEDパネル・ファン・ハブ・温湿度計 | DC機器 → 対象外 | 自主安全試験(温度上昇・絶縁) |
| キャビネット本体 | 電気用品ではない(照明器具を内蔵しない「家具」として設計) | — |

- **重要な設計判断**: ライトを本体に「内蔵・固定」せずマグネット着脱式の別部品とすることで、
  本体が「電気スタンド類・照明器具」とみなされるリスクを回避している。本体とライトのセット販売は問題ないが、
  **本体にライトを組込済み・直結配線済みの状態で出荷しない**こと(設計変更時はPSE該非を再判定)。
- 輸入事業者義務(届出・自主検査・記録3年)は前企画と同じ。

## 2. 電波法(技適)

- 無線機能なし構成を維持(温湿度計は非無線)。スマート化する場合は技適+PSE再整理(前企画 §2参照)。

## 3. 家具としての安全(本製品で新規に発生する論点)

| 論点 | 対応 |
|---|---|
| 転倒 | 総高1.4m・ガラス扉の家具。**転倒防止ベルト標準同梱**+取説で壁固定を必須表示。安定性試験(10°傾斜・扉端荷重)を出荷条件に |
| ガラス | **全面強化ガラス**(ロットごとに強化処理証明・破砕試験報告)。取説に「強化ガラス使用・衝撃時は細粒破砕」表示 |
| 指はさみ・エッジ | 板金はヘム曲げ/面取り、ファンは格子ガード(開口8mm以下) |
| 頭上重量物 | LEDパネルは磁石+**落下防止テザー必須**(SPEC-01)。磁石のみの頭上保持は不可 |
| 磁石 | 小棚・フックのネオジム磁石: 誤飲・医療機器(ペースメーカー)・磁気カード注意の日本語表示 |
| 消費生活用製品安全法 | 特定製品非該当だが、重大製品事故の報告義務(輸入事業者)に留意 |
| 家庭用品品質表示法 | 家具は対象品目外(タンス等の指定品目に非該当)。任意で材質・耐荷重を表示 |

### 4.1 RUDSTAの「形態」を参考にすることの適法性整理(2026-07時点の社内見解)

外形寸法をRUDSTAワイド同寸(800×370×1200)としたことに関するリスク整理。**結論: リスクは低いが、
量産金型発注前にJ-PlatPatの意匠検索と弁理士クリアランスを必須とする。**

| 法域 | 評価 | 根拠・条件 |
|---|---|---|
| 意匠権 | **要検索(唯一の実リスク)** | Inter IKEA Systems B.V.名義の日本登録意匠をJ-PlatPatで検索し、RUDSTA該当登録の有無と権利範囲を確認。登録があっても保護は図面記載の具体的形態であり、寸法値そのものは保護されない |
| 不正競争防止法 2条1項3号(形態模倣) | **ほぼ問題なし** | 保護は日本での最初の販売から3年。RUDSTAは遅くとも2021年前半に発売済み→2026年時点で期間経過。念のため国内発売日を確認 |
| 不競法 2条1項1号/2号(周知・著名商品等表示) | 低リスク | 形態自体が出所表示として周知/著名と認められるのは稀(例: 特徴的な家具の意匠でも高いハードル)。スチール枠ガラスキャビネットは同種品が多数あるありふれた形態 |
| 著作権 | 極めて低リスク | 量産家具は応用美術として著作物性が認められにくい(美術工芸品級の創作性が必要) |

**リスクをさらに下げる設計・実務上の根拠(すでに実施済み)**
1. 本製品は**デッドコピーではない**: 天井裏電源収納(EBOX)・四隅の配線グロメットポート・防水パン・
   マグネット壁面システム・脚部形状など、外観・構造とも独自要素が多数。「同一寸法」は互換性・設置性のための機能的選択であり、寸法自体に権利は及ばない
2. 開発経緯の記録: 本リポジトリのコミット履歴が「オーナーDIY機の課題解決から独自設計に至った」独立開発の証拠になる
3. マーケティングで「RUDSTA風」「IKEA互換」等の表示をしない(§4本文)— 形態面で問題がなくても、
   出所混同を誘う表示は不競法1号リスクを自ら作る行為
4. 自社意匠(天井裏EBOX+グロメットポート+マグネット壁面の組合せ)の出願検討 — 攻めの防衛

## 6. 取説・本体の安全表示(最低限)

1. 転倒防止ベルトで必ず壁に固定する
2. AC電装(アダプター・ハブ)は防滴設計の専用電源ボックス(天井裏マグネット収納)内のみ。箱外での裸置き・電源タップの庫内持ち込みは不可。異臭・誤動作時は即時使用中止
3. 入線はドリップループを作る/ベイの通気スリットを塞がない
4. 加湿器を庫内で使用しない
5. マグネット小棚の耐荷重2.0kg、LEDパネルはテザーを必ず掛ける
6. 強化ガラスへの強い衝撃・急冷急熱禁止/異臭・異音時は電源を抜く
7. 磁石注意(誤飲・ペースメーカー・磁気カード)
