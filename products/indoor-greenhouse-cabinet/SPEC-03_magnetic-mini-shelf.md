# SPEC-03 マグネット小棚(GRC-MSH・2枚組)

## 1. 概要

背面スチールパネルに磁力で貼り付け、小型植物(2〜3号ポット)を任意の高さに置ける小棚。
本体に2枚標準付属。棚のない一室空間で「小型株をライトに寄せる」ための主要アクセサリーであり、
増設単品SKU(2枚組)としても販売する。

## 2. 寸法・形状

| 項目 | 仕様 |
|---|---|
| 棚面(W×D) | 200 × 120 mm(±1mm) |
| 縁 | 三方立上り20mm(前縁は15mmで鉢が取り出しやすい形状)。受け皿を兼ね、水こぼれを保持 |
| 板厚 | スチール t1.0、粉体塗装 艶消し黒 |
| 質量 | ≤350 g/枚 |
| 角 | 全角R3以上、エッジはヘム曲げまたは面取り(手切れ防止) |

## 3. 磁石・保持力(最重要要件)

| 項目 | 仕様 |
|---|---|
| 磁石 | ネオジムN38以上×4点、背面全面にゴムマグネットシート併用(滑り防止・塗装保護) |
| 耐荷重 | **積載2.0kg**(2〜3号鉢×2〜3個相当)。t0.8塗装スチール垂直面で、定格の3倍(6kg)・24hでずり落ちなきこと |
| ずれ剛性 | 定格積載で棚先端の下がり(前傾)≤3° |
| 着脱 | 工具なしで着脱・高さ変更可。着脱時に塗装面に傷が付かないこと(ゴム面接触) |

## 4. 排水・防錆

- 棚面に水抜き穴は設けない(受け皿兼用のため)。隅にR付けし拭き取りやすくする。
- 塩水噴霧240h錆なきこと(常時高湿・水こぼれ前提)。

## 5. 試験(サンプル承認条件)

1. 保持: 実機相当スチール板(t0.8・粉体塗装)で6kg×24h → 滑落・ずれ10mm以内
2. 繰返し: 着脱1,000回後も保持力80%以上
3. 耐水: 水を張って48h → 錆・塗装膨れなきこと
4. 落下: 1m落下で変形・磁石脱落なきこと

## 6. 検査・表示・梱包

- 全数: 外観・エッジ・磁石固定。抜取: 保持力(n=3/ロット)
- AQL Major 2.5 / Minor 4.0
- 個装(2枚組): 耐荷重2.0kg表示、磁石注意(医療機器・磁気カード)の日本語表記
