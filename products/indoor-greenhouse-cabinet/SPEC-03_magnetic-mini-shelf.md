# SPEC-03 マグネット小棚(GRC-MSH・2枚組)

## 0. 調達方針: 既製マグネットキッチンラックから選定(専用設計しない)

冷蔵庫横ラック・マグネットスパイスラックとして既製品市場が確立しており(幅400×奥行125mm級・
耐荷重3kg超・粉体塗装スチール・黒がカタログ品で存在)、**既製モデルからの選定+色・ロゴ・
磁石強化のみカスタム(調達区分B)**とする。専用板金は既製で条件を満たすモデルが無い場合のフォールバック。

**選定の必須条件(キッチン用と温室用の違いがここに出る)**
1. **内寸**: 幅≥338 × 奥行≥110(プレステラ105×3が底面フラットに収まること)。
   キッチンラックは奥行80mm級が多いため要注意 — 奥行125mm級のモデルを選ぶ
2. **底面は水抜き構造(パンチング/ワイヤー/スリット)必須**(v0.5・オーナー指示で受け皿方式から転換):
   水やり後に棚上へ水が滞留しないこと。滴下は床の防水パン+水受けトレイが受ける設計思想。
   縁は鉢のズレ落ち防止の**低い立上り(10mm前後)**があること(高い縁=水溜まりの原因は不可)。
   ※キッチン系は「水切りラック」カテゴリにワイヤー/パンチング底の既製が豊富で、調達はむしろ容易になる
3. **防錆・磁力**: 常時RH70〜90%前提。塩水噴霧240h(§4)と、せん断保持≥9kgf(§3)を受入試験として継続適用。
   磁石が弱い場合はゴムマグネットシート増強を工場に指示
4. 幅の上限: **横並び運用(同一高さ2枚)をするならW≤370**(庫内幅760)。W400級を採用する場合は
   段違い配置を取説で指示する
5. カスタム項目: 艶消し黒・ロゴ・(必要なら)磁石増強のみ

以降の寸法・性能・試験は**選定基準(エンベロープ)および受入条件**として適用する。
`drawings.html` S5 も同様に選定基準図として使用。

## 1. 概要

背面スチールパネルに磁力で貼り付け、小型株を任意の高さに置ける小棚。本体に2枚標準付属+増設単品SKU。

**設計基準鉢: プレステラ105 × 3鉢/枚**(ユーザー要求により確定)。
プレステラ105 = 本体約92mm角、縁(フランジ)含め最大約105mm角、標準型H80mm(約0.35L)/深型H120mm(約0.52L)。
標準・深型のどちらでも3鉢が余裕をもって並び、指を入れて出し入れできること。

## 3. 磁石・保持力(最重要要件)

| 項目 | 仕様 |
|---|---|
| 定格積載 | **3.0 kg/枚**(プレステラ105深型×3鉢を湿潤土+株込みで約2.1〜2.4kgと想定し、余裕を含む) |
| 磁石 | ネオジムN38以上 φ25 × **6点**(バックプレート上列3・下列3)+背面全面ゴムマグネットシート(滑り防止・塗装保護) |
| ずり保持 | t0.8粉体塗装スチール垂直面で、**合計せん断保持 ≥9kgf**(定格の3倍)。24hでずり落ち・10mm以上のずれなきこと |
| 前傾(モーメント) | 定格積載を棚面前縁寄りに置いた状態で前傾 ≤3°。上列磁石の引剥がし耐力はH120のてこ腕で確保 |
| 着脱 | 工具なしで着脱・高さ変更可。着脱時に塗装面に傷が付かないこと(ゴム面接触) |

## 4. 排水・防錆(v0.5: 「溜める」から「落とす」へ)

- **棚上に水を溜めない**。鉢に水やりした余剰水は水抜き底からそのまま下へ落ち、最終的に床の
  防水パン+水受けトレイが受ける(=棚上の水やりがそのまま可能。受け皿の水捨て作業が不要)。
- 取説記載: 小棚の真下に湿気を嫌う物(温湿度計の直下設置など)を置かない/滴下が気になる場合は
  棚位置を床トレイの直上ゾーンに寄せる。
- 塩水噴霧240h錆なきこと(常時高湿・通水前提)。パンチング切断面の防錆処理(バリ取り+塗装回り込み)を確認。

## 5. 試験(サンプル承認条件)

1. 保持: 実機相当スチール板(t0.8・粉体塗装・垂直)で9kg×24h → 滑落なし・ずれ10mm以内
2. 前傾: プレステラ105深型×3(湿潤土入り・計約2.4kg)を前縁寄せで72h → 前傾≤3°、磁石剥離なし
3. 実用: 3鉢を各100回出し入れ → 棚のずれ・鉢の引っ掛かりなきこと
4. 繰返し: 着脱1,000回後も保持力80%以上
5. **通水**: プレステラ105×3に各500mlの水やり相当を通水 → 5分後に棚面の滞留水なきこと(水抜き性能)。加えて通水100回後に錆・塗装膨れなきこと
6. 落下: 1m落下で変形・磁石脱落なきこと

## 6. 検査・表示・梱包

- 全数: 外観・エッジ・磁石固定。抜取: 保持力(n=3/ロット)
- AQL Major 2.5 / Minor 4.0
- 個装(2枚組): **耐荷重3.0kg/枚・「105mm角ポット×3対応」「水抜き底(水は下へ落ちます)」表示**、磁石注意(誤飲・医療機器・磁気カード)の日本語表記

## 7. 配置の注意(取説・SPEC-06連携)

- 背面(内寸W760)に2枚を**同じ高さで横並び可**(350×2=700、中央間隙60mm)。段違い配置も可。
- レースウェイは庫内両隅(X=15/745)配置のため、**壁中央のどこに貼っても配線と干渉しない**(SPEC-06 §3 v0.5.1)。
- 推奨ゾーンはZ=350〜700(`SPEC-06` §3)。深型鉢使用時は上の障害物(ファン・パネル)との干渉に注意。
