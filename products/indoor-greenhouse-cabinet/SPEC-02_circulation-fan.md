# SPEC-02 循環ファン(GRC-FAN)

## 1. 概要

庫内の空気を24時間365日撹拌する120mm軸流ファン。フルセットには2基同梱し、
DIY機の実績配置(上部1基=天井付近の熱・湿気の撹拌、下部1基=床面株元の対流)を取説で推奨する。
一室空間で容積が大きいため、前企画(RUDSTA用80mm)から120mmに変更。

## 2. 寸法・構造

| 項目 | 仕様 |
|---|---|
| 外形 | 130 × 125 × 32 mm(±1mm)、ファン径120mm |
| 質量 | ≤250 g |
| ガード | 前後一体成形格子(指入れ防止・開口8mm以下)、艶消し黒 |
| 取付 | 背面マグネットベース(垂直保持≥自重×3)+チルト±45°(クリック保持)。背面吸気スペーサー30mm一体 |
| 材料 | フレーム・羽根 PBT(UL94 V-0) |

## 3. 電気仕様

| 項目 | 仕様 |
|---|---|
| 入力 | DC5V、USB-Aプラグ、ケーブル長2.0m(庫内高さ1.05m+機器ベイ引き回し分) |
| 消費電力 | ≤2.0W |
| 速度 | 3段階+OFF、インラインスイッチ |
| 保護 | ロック検出停止、逆接続保護 |

## 4. 性能・信頼性

| 項目 | 仕様 |
|---|---|
| 風量(High) | ≥40 CFM |
| 騒音 | Low ≤17dBA / High ≤25dBA(@50cm) |
| 軸受 | **デュアルボールベアリング必須**(24h連続・高湿) |
| 寿命 | MTBF ≥40,000h(40℃) |
| 防湿 | モーター基板コンフォーマルコーティング |
| 環境試験 | 40℃/90%RH・500h連続運転 → 異音・回転数15%以上の低下なきこと |

## 5. 検査・表示

- 全数: 通電・変速・異音。抜取: 風量・騒音(n=3/ロット)
- AQL Major 2.5 / Minor 4.0、RoHS報告書
- DC5V入力のためPSE対象外
