## 0. 前提整理 — 「FBAを使わない」が訴求に与える影響

| 前提 | 含意(ページ設計への反映) |
|---|---|
| 出品者出荷(神田氏物流) | プライムバッジが付かない → **検索結果ではメイン画像とレビューで勝つ比重が上がる**。メイン画像の品質が最重要 |
| 大型・重量制限なし | 800×370×1200・2個口・計約50kgをそのまま販売可。**「このサイズの完成品温室はAmazonに他にない」こと自体が差別化** |
| 配送を自社コントロール | 大型商品の配送不安(「玄関まで?」「不在時は?」「ガラスは割れない?」)が購入直前の離脱要因 → **画像6とA+で先回りして潰す** |
| FBA手数料なし | 大型FBA手数料(数千円/個)を回避 → 粗利を守れる。ただし配送品質のクレームは自社に直撃 → ISTA-2A梱包試験(SPEC-00 §8)が生命線 |
| **商標→ブランド登録が前提**(2026-07学習反映) | A+・動画・ブランドストア・相乗り排除はすべて**Amazonブランド登録**(商標が出願中でも申請可)が条件。登録には**商品/パッケージにブランド名が表示された画像**が必要 → ロゴ印字・銘板・化粧箱にブランド名を入れる設計を前提化。**商標・JANとも申請済み(2026-07)→次はブランド登録申請** |

## 1. Amazonの購買行動 → 画像設計の5原則

1. **メイン画像がクリック率を支配する**。検索結果ではメイン画像+価格+★しか見えない。
2. **モバイルでは箇条書きより先に画像がスワイプされる**。1画像=1メッセージ、文字は遠目でも読めるサイズ、詰め込まない。
3. ¥59,800は比較検討型の買い物。**顧客が頭の中で比較する相手(DIY総額・パルダリウムケージ・ビニール温室)を画像内で先回りして処理**する。
4. 前半3枚で「欲しい」を作り、**後半3枚で「買わない理由」(サイズ・組立・電気・配送)を消す**。
5. 規約: メイン画像は**純白背景RGB(255,255,255)・商品占有率85%以上・1,600×1,600px以上**・文字/バッジ/矢印装飾不可(違反=検索から除外)。**植物・鉢・雑貨は付属しない**ため、演出カットには「植物・小物は付属しません」注記を必ず入れる(誤認防止・レビュー荒れ防止)。
6. サブ画像は「**8枚ストーリー設計**」(CVRプレイブック準拠): 1枚目=入口(クリック) → 2〜3枚目=機能ベネフィット → 4〜6枚目=詳細・使用シーンで不安解消 → 7〜8枚目=信頼(比較・保証)。下記の画像2〜8はこの型に対応させている。

## 3. 画像構成(メイン1+サブ7+動画1 — 8枚ストーリー型)

### 画像1: メイン(白背景・規約準拠)
- **目的**: 検索結果でのクリック獲得。「家具に見える温室」を一目で。
- **構図**: 白背景・本体右斜め前45°(扉閉・庫内LED点灯状態は可: 商品自体の機能)。フルセット同梱の電装(LEDパネル・ファン・小棚)は庫内に装着した状態で撮影(=同梱物のみで構成)。
- **文字**: なし(規約)。
- **注意**: 植物は入れない(非同梱)。点灯で庫内が見える状態が「ただの黒いキャビネット」に見える事故を防ぐ。

### 画像2: ライフスタイル・ヒーロー(夜のリビング)
- **目的**: ②インテリア層の即決スイッチ。「光る家具」の情緒。ページ内の主役画像。
- **構図**: 夜のリビング、間接照明の中で本体だけが緑に光る。中は大鉢+壁の小棚+側面メッシュのビカクシダ(スタイリング)。
- **文字**: 「リビングに、熱帯をひと部屋。」+小さく「W800×D370×H1200/植物は付属しません」
- **根拠**: ピッチのヒーローと同じ世界観。SNS転載にも耐える1枚に投資する。

### 画像3: 課題解決3点(このカテゴリで唯一の「設計済み」)
- **目的**: DIY経験者・検討済み層に「これは分かってる製品だ」と伝える。競合(ただのガラスケース)との決定的差。
- **構図**: 3分割または本体+吹き出し3点。①背面四隅のφ40グロメット(コードを通した接写)②背面上部の電源ボックス(開けた状態でアダプタが収まっている)③マグネット小棚・フック(着脱の手)。
- **文字**: 「配線も、電源も、湿度も。ぜんぶ設計済み。」/「配線穴、最初から開いています(φ40×4)」「アダプターは庫内の防滴ボックスへ」「壁はぜんぶマグネット」
- **根拠**: README §1の差別化の核。DIY総額と比較される前に「自作では面倒な部分が全部済んでいる」を先に見せる。

### 画像4: 湿度性能(株を守る保険)
- **目的**: ①コレクター層の本丸。「エアコンの部屋で湿度80%」の証拠感。
- **構図**: 温湿度計のアップ(例: 30℃/75%RH)+庫内のしっとりした葉のマクロ。密閉の作り(扉ガスケット・扉中央の召し合わせシール・膜付きグロメット)を小さく図解。
- **文字**: 「エアコンの効いた部屋で、湿度80%の環境をつくる。」+「扉ガスケット+召し合わせシール+膜付きグロメットの全密閉(工場装着済み)」
- **注意**: 数値は試作実測値に差し替えること(景表法・優良誤認回避)。「湿度80%」は実測が取れるまで「高湿度環境」と表現。

### 画像5: 一室空間と水やり動線
- **目的**: 「棚が邪魔」問題の解決と、日常運用の楽さ(=買った後の生活を想像させる)。
- **構図**: 2カット構成。①棚なし空間に大鉢+吊りビカク(縦の抜け感)②波形底トレイを引き出して水を捨てる手元。
- **文字**: 「棚は、つけませんでした。大きく育てるための余白です。」/「そのまま水やりOK——水は波形底トレイへ。鉢底は濡れない」
- **根拠**: RUDSTA系DIYの2大不満(棚・水)への回答。

### 画像6: サイズ・組立・設置(不安の一括処理)
- **目的**: 大型商品の購入直前離脱を防ぐ。ここが出品者出荷モデルの勝負どころ。
- **構図**: 寸法インフォグラフィック(前面+側面・W800×D370×H1200・壁際20mm)+組立の様子(2人・六角レンチ1本)+転倒防止金具。
- **文字**: 「RUDSTA…」は使わない→「幅80cmの省スペース。壁際2cmまで寄せられる」/「組立は2人で約40分・工具は付属の六角レンチだけ」/「転倒防止金具・ベルト標準付属」/「2個口でお届け(合計約50kg)」

### 画像7: 電気・ランニング・同梱物一覧
- **目的**: 「電気が怖い」「維持費は?」の処理と、「これ1箱で完結」の物量感。

- **注意**: 電気代は電力単価の前提を小さく併記(例: 31円/kWh)。

### 画像8: 比較・保証(信頼の締め)
- **目的**: 8枚ストーリーの「信頼」枠。比較検討の最後のひと押し+購入後の安心。

## 6. 制作実務メモ

1. **必要素材(試作機で撮影)**: 白抜き物撮り(メイン)/夜のリビング設置カット/接写(グロメット・EBOX内部・召し合わせシール・温湿度計)/組立2人カット/同梱物並べ/寸法図(drawings.htmlから起こす)。
2. **規約チェック**: メイン=白背景・文字なし・同梱物のみ/演出カットに「植物・小物は付属しません」/レビュー誘導文言は書かない。
3. **景表法チェック**: 温湿度・電気代・組立時間はすべて**試作実測に差し替えてから公開**(実測前は断定を避ける)。比較表の他社価格は調査日付きで保存(MARKETING §2の出典を維持)。
4. 「開梱設置サービス」「寒冷地セット」は発売時点で提供できる場合のみ記載(できないなら画像からも落とす)。
5. **ブランド登録用の素材**: 商品本体またはパッケージに**ブランド名が恒久表示された写真**を撮っておく(ブランド登録審査で必要)。ロゴ印字はSPEC-01(LED)・SPEC-00(本体ラベル)・化粧箱で対応済み。
6. **レビューは分析対象であって操作対象ではない**: 報酬付きレビュー依頼・レビューの編集/削除依頼はAmazonポリシー違反(アカウント停止リスク)。レビュー獲得は「コスパ価格+同梱サンクスカード(規約準拠の中立文面)+初期不良の即交換」で自然に積む。
