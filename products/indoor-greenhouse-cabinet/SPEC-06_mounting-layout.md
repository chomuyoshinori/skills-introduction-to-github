> - **v0.4**: 天板を無孔・ソリッド化(機器収納ベイ廃止・上に物が置ける・耐荷重10kg)。アダプタ類は
>   背面外側のユーティリティポケットへ。庫内高さ950→**1020mm**。旧P2(AC入線穴)廃止
> - **v0.6(オーナー決定)**: EBOXをポケット→**庫内天井裏(天板下面)のマグネット収納**へ。旧P1穴×2・

>   防滴EBOX(開口は下面のみ)・天井=庫内で最も結露しにくい位置・落下防止テザー・30日高湿通電試験(§8)で低減
> - **v0.6.1(オーナー切削実証)**: 全穴をφ40に拡大(ACプラグが通る)・P-BIGスロット廃止
> - **v0.7(オーナー指示・シンプル化)**: **排気・給気ベントを廃止**(実測で必要になればv1.1で追加)。
>   穴は**φ40×4・背面四隅=P1(左上)/P2(右上)/P3(左下)/P4(右下)**に統一し、全穴に
>   **膜付き電気ゴムグロメットを工場装着** — 使う穴だけユーザーがカッターで膜に切込みを入れて通線し、
>   未使用穴は膜のまま完全密閉(盲栓・割りグロメット廃止・部品1種類)

## 0. 設計思想

**「固定はゼロ、すべてマグネット着脱式」+「天板無孔」**。
電装(LEDパネル・ファン・電源ボックス・配線カバー)を工具なしで外して机上でメンテできる。

### 穴・取付位置の設計原則
1. **庫内完結原則(v0.6)**: 給電系は庫内天井裏のEBOXで完結し、外に出るのはACコード1本のみ(P2=背面右上グロメット経由)
2. **上面無孔原則**: 天板には穴・開口を設けない(上に物を置ける/ホコリ・水の侵入経路を作らない)
3. **水回避**: 下部の穴は庫内床から+120mm
4. **扉面に穴を開けない**: 密閉性(ガスケット)を壊さない
5. 穴構成(**v0.7**): **φ40×4・背面四隅**(P1〜P4)。全穴に膜付き電気ゴムグロメットを工場装着し、
   **使う穴だけユーザーがカッターで膜に十字の切込みを入れて通線**する(未使用穴は膜のまま完全密閉)。
   φ40はACコンセントプラグが通ることをオーナーが切削実証済み(コードは1穴に3本まで共存可)。
   部品はφ40膜付きグロメット1種類のみ(盲栓・割りグロメット廃止・プレス簡素化)。
   ※大型トランス一体プラグ等が通らない機器は、アダプタごと庫内(天井裏)運用で対応

## 1. 座標系

庫内有効空間(W760 × D330 × **H1020**)に対し、**原点=庫内の左・背面・床の角**。
- X: 幅方向 0→760(左→右) / Y: 奥行 0→330(背面→扉) / Z: 高さ 0→1020(床→天板下面)

## 2. 天板(下面=庫内天井)

- **貫通穴なし**。下面はスチール磁性面で、フック磁石(GRC-HOOK32)の推奨位置マーカー×4を焼付印刷:
  **HK1(90,185) HK2(290,185) HK3(470,185) HK4(670,185)**(吊りピッチ200、パネル中心Y=185 — v0.6でEBOX吊り座を避けて前寄せ)
- **EBOX吊り座(v0.6)**: 下面後方 X=220〜540 / Y=5〜165 に電源ボックスをマグネット吸着(天井=引張方向で磁石が最も強い)。
  取付位置マーカー(四隅の印刷)。EBOX厚45mmはZ=975〜1020を占有し、吊りパネル(発光面Z≤970)と干渉しない
- 上面: ソリッド・補強リブ2本(ハット断面)・**耐荷重10kg(等分布)**。鉢や小物を置ける。
- RUDSTA取説(step17-18)と同じ「前からスライド挿入→ボルト固定」方式を踏襲(組立性の実績方式)。

## 4. 電源ボックスの庫内天井収納(v0.6・オーナー決定)

「不安点はあっても、天板の裏にマグネットで収納したい」— EBOXを**庫内天井裏(天板下面・後方)**へ移設する。

| 項目 | 仕様 |
|---|---|
| 位置 | 天板下面 X=220〜540 / Y=5〜165(後方寄せ)。Z=975〜1020を占有し吊りLEDパネルと干渉しない |
| 固定 | マグネット(天井=**引張方向**で磁石が最も有利)+**落下防止テザー必須**(天井フレーム掛け・頭上重量物のPL対策) |
| AC引き出し | EBOX下辺切欠き→**天井際を右へ→P2(φ40・680,950)のグロメット膜に十字切込み→庫外へ**→屋外レースウェイで床のコンセントまで |
| 廃止 | 背面ポケット・リアカバー・旧P1小穴×2(v0.6)、P-BIGスロット(v0.6.1)、ベント×2・盲栓・割りグロメット(v0.7)。**背面突出ゼロ→壁クリアランス20mm** |
| リスク低減 | ①EBOXは防滴仕様(§5: 開口は下面のみ・IPX2相当) ②天井は庫内で最も暖かく結露しにくい ③全ケーブルにドリップループ ④30日高湿通電試験(§8)を量産ゲートに ⑤取説: 異臭・誤動作時は即時使用中止 |
| 代替(選択肢) | 湿気が気になるユーザー向けに**庫外運用も可**: EBOXをマグネットポーチ(GRC-POUCH)位置=背面外側に貼り、ACも機器ケーブルもP2経由にする(取説に両方式を記載) |

## 7. 配線経路(標準セットアップ)

```
コンセント → [屋外レースウェイ(背面外側)] ↑ → P2(680,950)のグロメットから庫内へ → [EBOX(天井裏): アダプター+ハブ]
  ├─ LED-A/B: ハブ → 天井裏を這ってパネルへ(リード1.0mを短く束ねて直結・庫内露出ほぼゼロ)
  ├─ FAN上: ハブUSB → 天井際 → (560,860)
  └─ FAN下: ハブUSB → 天井際を左へ → [RC-L(X=15)] ↓ → 横引き → (200,280)
外に出るのはACコード1本だけ。P2の膜がコードに密着して密封(切込みはコード径ぶんで足りる)
```

## 7.2 持ち込み機器(アダプタ一体型)の配線例 — v0.6.1

市販LEDパネル・ファンには「本体⇔ACアダプタ⇔ACプラグが一体で切り離せない」製品が多い。
v0.6.1の運用は**「アダプタは庫内・プラグだけ外へ」**:

```
[市販LEDパネル(庫内に吊る)]─一体ケーブル─[ACアダプタ本体: 天井裏に磁石留め(EBOX横・付属フック磁石)]
                                          └─ ACプラグ ─→ P2(φ40グロメット)から庫外へ → コンセント
```
- φ40はACプラグが通ることをオーナーがDIYで実証済み。**コードはP2 1穴に3本まで共存**
  (付属AC1本+持ち込み2本を想定)。膜の切込みがコードに密着するので、戻し作業は不要
- 大型トランス一体プラグ等が通らない機器のみ、庫外ポーチ(GRC-POUCH)運用に切替
- **裸のアダプタを床・棚に直置きしない**(天井裏=最も結露しにくい位置に磁石留め。取説で指示)

## 8. 試験(サンプル承認条件)

1. フック磁石: 天井面(天板下面)で定格3倍×24h+扉開閉衝撃100回 → 滑落なし(従来どおり)
2. EBOX: 満載1.3kgで**天井吊り**・定格3倍引張24h+扉開閉500回 → 脱落なし。テザー単体で自重10倍静荷重
3. **高湿通電30日(v0.6追加・量産ゲート)**: EBOX満載を庫内相当(30℃/RH90%・ファン循環あり)で30日通電 → 結露痕・腐食・絶縁劣化・誤動作なきこと
4. **天板荷重**: 10kg等分布・24h → 永久たわみなし。中央集中5kgで補強リブ座屈なし
5. レースウェイ・印刷: 従来どおり(40℃/95%RH 240h・拭き取り1,000回)
6. **グロメット膜(v0.7)**: 未切込み状態でSPEC-00 §8-8の湿度保持試験に合格/十字切込み+コード3本通線で裂けの進展・脱落なきこと(着脱50回+コード引張10N)
