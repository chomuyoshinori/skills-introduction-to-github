# SPEC-06 マグネット・マウントシステムと取付レイアウト(穴位置・座標)

> 寸法体系 **v0.4**: 外形はRUDSTAワイド同寸(W800×D370×総高1200)。
> **v0.4変更(オーナー指示+RUDSTA取説の参照)**:
> ①天板は**無孔・ソリッド**(上に物が置ける・耐荷重10kg)— 機器収納ベイを廃止
> ②アダプター類は**背面外側上部のユーティリティポケット**(マグネット式EBOX+マグネット式カバー)へ移設
> ③これにより庫内高さが 950→**1020mm** に拡大(ベイ分を庫内に還元)
> ④P2(AC入線穴)は廃止 — ACコードはポケットから直接下ろすため穴が不要になった(穴は計4つに減)
> **v0.6(オーナー決定)**: EBOXを背面ポケット→**庫内天井裏(天板下面)のマグネット収納**へ変更。
> P1穴×2とリアカバー(GRC-RCOV)を廃止(穴は**P-BIG+P3×2の計3つ**に)。背面突出が消え、壁クリアランスは60→**20mm**。
> AC機器を高湿庫内に置くリスクは、防滴EBOX(開口は下面のみ)・天井=庫内で最も暖かく結露しにくい位置・
> 落下防止テザー・30日高湿通電試験(§8)で低減する

## 0. 設計思想

**「固定はゼロ、すべてマグネット着脱式」+「天板無孔」**。
電装(LEDパネル・ファン・電源ボックス・配線カバー)を工具なしで外して机上でメンテできる。

### 穴・取付位置の設計原則
1. **庫内完結原則(v0.6)**: 給電系は庫内天井裏のEBOXで完結し、外に出るのはACコード1本のみ(P-BIG経由)
2. **上面無孔原則**: 天板には穴・開口を設けない(上に物を置ける/ホコリ・水の侵入経路を作らない)
3. **水回避**: 下部の穴は庫内床から+120mm
4. **扉面に穴を開けない**: 密閉性(ガスケット)を壊さない
5. 穴構成(v0.6): **P-BIG 110×60 ×1(AC出し兼持ち込み用)+φ30×2(P3・将来拡張)の計3穴**。P1は廃止。
   P-BIGは市販の「アダプタ一体型」LED・AC機器を持ち込むための穴 — **ACプラグ(約40×22)も
   ACアダプタ本体(〜145×60×36・斜め通し)も通る**。割りシリコン膜グロメット+未使用時スナップ盲蓋

## 1. 座標系

庫内有効空間(W760 × D330 × **H1020**)に対し、**原点=庫内の左・背面・床の角**。
- X: 幅方向 0→760(左→右) / Y: 奥行 0→330(背面→扉) / Z: 高さ 0→1020(床→天板下面)

## 2. 天板(下面=庫内天井)

- **貫通穴なし**。下面はスチール磁性面で、フック磁石(GRC-HOOK32)の推奨位置マーカー×4を焼付印刷:
  **HK1(90,185) HK2(290,185) HK3(470,185) HK4(670,185)**(吊りピッチ200、パネル中心Y=185 — v0.6でEBOX吊り座を避けて前寄せ)
- **EBOX吊り座(v0.6)**: 下面後方 X=220〜540 / Y=5〜165 に電源ボックスをマグネット吸着(天井=引張方向で磁石が最も強い)。
  取付位置マーカー(四隅の印刷)。EBOX厚45mmはZ=975〜1020を占有し、吊りパネル(発光面Z≤970)と干渉しない
- 上面: ソリッド・補強リブ2本(ハット断面)・**耐荷重10kg(等分布)**。鉢や小物を置ける。
- RUDSTA取説(step17-18)と同じ「前からスライド挿入→ボルト固定」方式を踏襲(組立性の実績方式)。

## 4. 電源ボックスの庫内天井収納(v0.6・オーナー決定)

「不安点はあっても、天板の裏にマグネットで収納したい」— EBOXを**庫内天井裏(天板下面・後方)**へ移設する。

| 項目 | 仕様 |
|---|---|
| 位置 | 天板下面 X=220〜540 / Y=5〜165(後方寄せ)。Z=975〜1020を占有し吊りLEDパネルと干渉しない |
| 固定 | マグネット(天井=**引張方向**で磁石が最も有利)+**落下防止テザー必須**(天井フレーム掛け・頭上重量物のPL対策) |
| AC引き出し | EBOX下辺切欠き→背面沿いに下ろさず**天井際を右へ→P-BIG(655,950)から庫外へ**→屋外レースウェイで床のコンセントまで |
| 廃止 | 背面ユーティリティポケット・リアカバー(GRC-RCOV)・P1穴×2。**背面突出ゼロ→壁クリアランス20mm**(ACコード分)に短縮 |
| リスク低減 | ①EBOXは防滴仕様(§5: 開口は下面のみ・IPX2相当) ②天井は庫内で最も暖かく結露しにくい ③全ケーブルにドリップループ ④30日高湿通電試験(§8)を量産ゲートに ⑤取説: 異臭・誤動作時は即時使用中止 |
| 代替(選択肢) | 湿気が気になるユーザー向けに**庫外運用も可**: EBOXをマグネットポーチ(GRC-POUCH)位置=背面外側に貼り、ACも機器ケーブルもP-BIG経由にする(取説に両方式を記載) |
| **役割分担(誤解防止)** | 保持はEBOX自身のマグネット+テザーのみ。P-BIG穴に荷重をかけない。P-BIGを通るのはACコード(付属系)と持ち込み機器ケーブル |

## 7. 配線経路(標準セットアップ)

```
コンセント → [屋外レースウェイ(背面外側)] ↑ → P-BIG(655,950)から庫内へ → [EBOX(天井裏): アダプター+ハブ]
  ├─ LED-A/B: ハブ → 天井裏を這ってパネルへ(リード1.0mを短く束ねて直結・庫内露出ほぼゼロ)
  ├─ FAN上: ハブUSB → 天井際 → (560,860)
  └─ FAN下: ハブUSB → 天井際を左へ → [RC-L(X=15)] ↓ → 横引き → (200,280)

```

## 7.2 持ち込み機器(アダプタ一体型)の配線例 — v0.4.1で正式サポート

市販LEDパネル・ファンには「本体⇔ACアダプタ⇔ACプラグが一体で切り離せない」製品が多い。
その場合はφ30ではなく**P-BIGフリーポート**を使う:

```
[市販LEDパネル(庫内に吊る)]
   └─ 一体ケーブル ─→ P-BIG(110×60)からアダプタ本体ごと庫外へ ─→ [マグネットポーチに収納]
                                                                └─ ACプラグ → コンセント
```
- ポーチは磁石でどこにでも貼れるため、**コンセントに近い高さまで下ろせば
  アダプタ→コンセントの距離問題は起きない**(ポート→ポーチ間は屋外レースウェイで隠す)
- 通せるもの: ACプラグ(約40×22)、ACアダプタ本体(〜145×60×36 斜め通し)、電源タップのプラグ、USB/DCプラグ全般
- 通した後は割り膜グロメットをケーブル周りに戻して隙間を塞ぐ。未使用時はスナップ盲蓋で密封
- 持ち込みAC機器のアダプタは**庫外(ポーチ)推奨**。庫内に置く場合は付属EBOX(防滴)内のみ——**裸のアダプタ・電源タップの庫内直置きは不可**(高湿トラッキング・腐食。取説×表示)

## 8. 試験(サンプル承認条件・v0.4差分)

1. フック磁石: 天井面(天板下面)で定格3倍×24h+扉開閉衝撃100回 → 滑落なし(従来どおり)
2. EBOX: 満載1.3kgで**天井吊り**・定格3倍引張24h+扉開閉500回 → 脱落なし。テザー単体で自重10倍静荷重
3. **高湿通電30日(v0.6追加・量産ゲート)**: EBOX満載を庫内相当(30℃/RH90%・ファン循環あり)で30日通電 → 結露痕・腐食・絶縁劣化・誤動作なきこと
4. **天板荷重**: 10kg等分布・24h → 永久たわみなし。中央集中5kgで補強リブ座屈なし
5. レースウェイ・印刷: 従来どおり(40℃/95%RH 240h・拭き取り1,000回)
