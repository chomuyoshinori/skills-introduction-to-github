# SPEC-06 マグネット・マウントシステムと取付レイアウト(穴位置・座標)

> 寸法体系 **v0.4**: 外形はRUDSTAワイド同寸(W800×D370×総高1200)。
> **v0.4変更(オーナー指示+RUDSTA取説の参照)**:
> ①天板は**無孔・ソリッド**(上に物が置ける・耐荷重10kg)— 機器収納ベイを廃止
> ②アダプター類は**背面外側上部のユーティリティポケット**(マグネット式EBOX+マグネット式カバー)へ移設
> ③これにより庫内高さが 950→**1020mm** に拡大(ベイ分を庫内に還元)
> ④P2(AC入線穴)は廃止 — ACコードはポケットから直接下ろすため穴が不要になった(穴は計4つに減)

## 0. 設計思想

**「固定はゼロ、すべてマグネット着脱式」+「天板無孔」**。
電装(LEDパネル・ファン・電源ボックス・配線カバー)を工具なしで外して机上でメンテできる。

### 穴・取付位置の設計原則
1. **背面集約原則**: 給電穴は背面上段パネルに集約し、庫内の露出配線は背面沿いの縦区間のみ(レースウェイ内)
2. **上面無孔原則**: 天板には穴・開口を設けない(上に物を置ける/ホコリ・水の侵入経路を作らない)
3. **水回避**: 下部の穴は庫内床から+120mm
4. **扉面に穴を開けない**: 密閉性(ガスケット)を壊さない
5. 穴構成(v0.4.1): **φ30×4(P1×2・P3×2、DC低圧専用)+大型フリーポート×1(P-BIG 110×60)**。
   P-BIGは市販の「アダプタ一体型」LED・AC機器を持ち込むための穴 — **ACプラグ(約40×22)も
   ACアダプタ本体(〜145×60×36・斜め通し)も通る**。割りシリコン膜グロメット+未使用時スナップ盲蓋

## 1. 座標系

庫内有効空間(W760 × D330 × **H1020**)に対し、**原点=庫内の左・背面・床の角**。
- X: 幅方向 0→760(左→右) / Y: 奥行 0→330(背面→扉) / Z: 高さ 0→1020(床→天板下面)

## 2. 天板(下面=庫内天井)

- **貫通穴なし**。下面はスチール磁性面で、フック磁石(GRC-HOOK32)の推奨位置マーカー×4を焼付印刷:
  **HK1(90,165) HK2(290,165) HK3(470,165) HK4(670,165)**(吊りピッチ200、パネル中心X=190/570)
- 上面: ソリッド・補強リブ2本(ハット断面)・**耐荷重10kg(等分布)**。鉢や小物を置ける。
- RUDSTA取説(step17-18)と同じ「前からスライド挿入→ボルト固定」方式を踏襲(組立性の実績方式)。

## 4. 背面ユーティリティポケット(v0.4新設・課題②への回答)

「アダプタは背面にマグネットで、背面上部にカバーして置く」— 本体外側の背面上部に、
**EBOX(マグネット着脱)+スチールカバー(マグネット着脱)**で構成する収納を設ける。板金加工は不要(穴P1×2のみ)。

| 項目 | 仕様 |
|---|---|
| 位置 | 背面外側・上部中央: EBOX X=220〜540 / Z=840〜1000(P1穴の真裏) |
| カバー(GRC-RCOV) | スチールt0.6 プレス箱型 **W380×H200×D55**、艶消し黒、マグネット4点で背面に吸着。上辺は天板と面一、下辺にケーブル出口スリット(下向き=ドリップループ形成)。側面通気スリット開口率≥25% |
| 壁クリアランス | **60mm**(カバー奥行55+余裕)。取説で「壁から6cm離して設置」を明記。転倒防止金具のスペーサーで同時に吸収(§6) |
| メンテ | カバーを外す(磁石)→EBOXを外す(磁石)→机上で配線。工具ゼロは従来どおり |
| **役割分担(誤解防止)** | **P1穴はDC低圧ケーブルの通線専用**(LED/ファンのDCプラグφ5.5が通る。ACプラグは通さない—ACはEBOX下辺切欠きから直接出す)。**EBOX・カバーの保持は自身のマグネットのみで、P1穴には荷重をかけない**(グロメットのシール変形・ケーブル擦れ防止) |

## 7. 配線経路(標準セットアップ)

```
コンセント → [屋外レースウェイEXT(背面下部)] → EBOX下辺切欠き → [EBOX: アダプター+ハブ](背面ポケット内)
  ├─ LED-A: ハブ → P1a(250,970) → 庫内へ ↓ [RC-L] 沿い → パネルA(リード1.0m直結)
  ├─ LED-B: ハブ → P1b(510,970) → 同上 ↓ [RC-R] → パネルB
  ├─ FAN上: ハブUSB → P1b → (560,930)
  └─ FAN下: ハブUSB → P1a ↓ [RC-L] → (200,280)
最後に [GRC-RCOVカバー] を被せて配線・グロメットごと隠す
```

## 7.2 持ち込み機器(アダプタ一体型)の配線例 — v0.4.1で正式サポート

市販LEDパネル・ファンには「本体⇔ACアダプタ⇔ACプラグが一体で切り離せない」製品が多い。
その場合はφ30ではなく**P-BIGフリーポート**を使う:

```
[市販LEDパネル(庫内に吊る)]
   └─ 一体ケーブル ─→ P-BIG(110×60)からアダプタ本体ごと庫外へ ─→ [マグネットポーチに収納]
                                                                └─ ACプラグ → コンセント
```
- ポーチは磁石でどこにでも貼れるため、**コンセントに近い高さまで下ろせば
  アダプタ→コンセントの距離問題は起きない**(ポート→ポーチ間は屋外レースウェイで隠す)
- 通せるもの: ACプラグ(約40×22)、ACアダプタ本体(〜145×60×36 斜め通し)、電源タップのプラグ、USB/DCプラグ全般
- 通した後は割り膜グロメットをケーブル周りに戻して隙間を塞ぐ。未使用時はスナップ盲蓋で密封
- なお**AC機器・アダプタ・タップの庫内設置は不可**(高湿によるトラッキング・腐食。取説×表示)

## 8. 試験(サンプル承認条件・v0.4差分)

1. フック磁石: 天井面(天板下面)で定格3倍×24h+扉開閉衝撃100回 → 滑落なし(従来どおり)
2. EBOX: 満載1.3kgで背面縦付け・扉開閉500回+24h → ずれ10mm以内、脱落なし
3. RCOVカバー: 着脱500回で磁石脱落なし。装着状態で軽い接触(2kgf水平)で落下しないこと
4. **天板荷重**: 10kg等分布・24h → 永久たわみなし。中央集中5kgで補強リブ座屈なし
5. レースウェイ・印刷: 従来どおり(40℃/95%RH 240h・拭き取り1,000回)
