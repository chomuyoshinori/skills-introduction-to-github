米国株のリサーチレポートを、リサーチ・分析チームを使って作成してください。

## 手順
1. **日付の確定**: 今日の日付(JST)を確認し、`DATE=YYYY-MM-DD` とする。データ基準日は米国市場の直近取引日(時差に注意)。作業ディレクトリ `reports/work/us-DATE/` を使う。
2. **前提の読み込み**: `US_EQUITY_PROFILE.md` と `LESSONS.md` を読む。`DECISION_LOG.md` の [US] タグから「検証予定」期日到来の未検証項目を宿題リストとして控える。
3. `us-equity-analyst` を起動する(出力先: `reports/work/us-DATE/us-equity.md`)。プロンプトに「今日の日付と米国市場のデータ基準日」「出力先」「宿題」を含め、以下を分析させる:
   - 地合い: S&P500/NASDAQ、米金利・FRB、USD/JPY、セクターの流れ
   - 個別: `$ARGUMENTS` に銘柄指定があればそれを対象に。なければ US_EQUITY_PROFILE.md の保有銘柄
   - 各銘柄で forward P/E or PSR(計算根拠付き)・直近決算のビート/ミス・希薄化・次回決算日・為替/税の含意・リスクを必ず確認
4. **レッドチーム検証(必須ゲート)**: `red-team-critic` に出力ファイルを読ませて検証させる(出力先: `reports/work/us-DATE/redteam.md`)。特に「バリュエーション過熱(『割安』の成長前提依存)」「プレ収益銘柄の希薄化・ランウェイの検算」「為替リスク」「資産クラス横断のテーマ集中(3プロファイル突き合わせ)」を重点検証させる。
5. **差し戻し(最大1回)**: 「要差し戻し」の場合のみ、us-equity-analyst に自身の出力ファイルを修正させ、red-team-critic に修正箇所のみ再検証させて `redteam.md` に追記させる(再検証も1回のみ)。収束しなければ未解決論点として編集長に渡す。
6. **統合**: `report-editor` に作業ディレクトリの全ファイルを読ませて統合 → `reports/us-DATE.md` に保存、主要な見立てを `DECISION_LOG.md` に「[US]」タグ付きで追記、変化のあった銘柄のテーゼ(`theses/`)を更新、「未解決の宿題」セクションを設けさせる。
7. **完了確認**: `reports/us-DATE.md` と DECISION_LOG.md 追記を確認する。欠けていれば report-editor に1回だけ再依頼し、それでも欠ける場合は不足内容をチャットに報告して終了する。
8. **チャット報告**: 「今日の要点(3行)」「最も注意すべき点」「レッドチームが修正したデータ誤り(あれば)」「未解決の宿題のうちユーザーの回答・入力が必要なもの」を要約する。

## 注意
- 米国株は円換算で為替影響を受ける旨、配当源泉税・申告分離の税制を明記する。
- 投機的・プレ収益銘柄(例: IONQ)は株式枠内でも「高リスク」と明示する。
- `reports/work/` は中間成果物置き場(コミット対象外)。
