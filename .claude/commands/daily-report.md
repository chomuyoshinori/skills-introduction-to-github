日本株の日次リサーチレポートを、リサーチ・分析チームを使って作成してください。

## 手順
1. **日付の確定**: 今日の日付(JST)を確認し、`DATE=YYYY-MM-DD` とする。土日祝、または大引け(15:30 JST)前の実行なら「当日終値は未確定。データ基準日は直近の確定した営業日」であることを以降の全エージェントに伝える。作業ディレクトリ `reports/work/DATE/` を使う。
2. **前提の読み込み**: `INVESTMENT_PROFILE.md`(保有銘柄・株数)と `LESSONS.md` を読む。`DECISION_LOG.md` から「検証予定」期日到来の未検証項目を宿題リストとして控える。
3. **4アナリストを1つのメッセージで並行起動**する。各プロンプトには「今日の日付とデータ基準日」「出力先ファイルパス」「関連する宿題」を必ず含める:
   - `macro-market-analyst` → `reports/work/DATE/macro.md`
   - `news-curator` → `reports/work/DATE/news.md`
   - `sector-theme-analyst` → `reports/work/DATE/sector.md`
   - `equity-analyst` → `reports/work/DATE/equity.md`($ARGUMENTS で銘柄指定があればそれを対象に。なければ保有銘柄+ウォッチリストをウェイト順に)
4. **レッドチーム検証(必須ゲート。飛ばさない)**: `red-team-critic` に4ファイルを読ませて検証させる(出力先: `reports/work/DATE/redteam.md`)。データ監査(日付整合・重要数値の一次ソース照合・導出値の検算)、宿題チェック、**資産クラス横断のテーマ集中(3プロファイル突き合わせ)**を必ず含めるよう指示する。
5. **差し戻し(最大1回)**: レッドチームが「要差し戻し」と判定した場合のみ、対象アナリストに**自身の出力ファイルを修正**させ、その後 `red-team-critic` に**修正箇所のみ再検証**させて結果を `redteam.md` に追記させる(再検証も1回のみ)。収束しなければ未解決論点としてそのまま編集長に渡す。
6. **統合**: `report-editor` に `reports/work/DATE/` の全ファイルを読ませて統合させる。`reports/DATE.md` に保存、主要な見立てを `DECISION_LOG.md` に追記、「未解決の宿題」セクションを設けさせる。
7. **完了確認**: `reports/DATE.md` の存在と DECISION_LOG.md の追記を確認する。欠けていれば report-editor に**1回だけ**再依頼し、それでも欠ける場合は不足内容をチャットに報告して終了する。
8. **チャット報告**: 「今日の要点(3行)」「最も注意すべき点」「レッドチームが修正したデータ誤り(あれば)」「未解決の宿題のうちユーザーの回答・入力が必要なもの」を要約する。

## 注意
- 引数 `$ARGUMENTS` に銘柄(社名/証券コード)が渡されたら、個別株分析の対象にする。
- 本レポートは情報整理であり投資助言ではない旨を、レポート冒頭に必ず明記する。
- `reports/work/` は中間成果物置き場(コミット対象外)。最終成果物は `reports/DATE.md` と DECISION_LOG.md の追記。
