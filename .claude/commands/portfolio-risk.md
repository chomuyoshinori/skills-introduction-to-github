ポートフォリオ横断のリスク定量点検を実行してください。あなた(オーケストレーター)が直接、データ取得と計算を行います(サブエージェント不要。計算は必ず python3 で行い、暗算しない)。

## 手順
1. **日付の確定**: 今日の日付(JST)を確認し、`DATE=YYYY-MM-DD` とする。
2. **保有の読み込み**: 3プロファイル(`INVESTMENT_PROFILE.md` / `US_EQUITY_PROFILE.md` / `CRYPTO_PROFILE.md`)から全保有銘柄と数量を読み、`theses/_portfolio.md` で既知の横断リスクを確認する。
3. **価格系列の取得**(過去12ヶ月・日次。取得できた範囲で進め、失敗した銘柄は「取得不能」と記録して続行する):
   - 日本株: stooq の CSV(例: `https://stooq.com/q/d/l/?s=6594.jp&i=d`)を WebFetch
   - 米国株: 同(例: `https://stooq.com/q/d/l/?s=nvda.us&i=d`)
   - 為替: 同(`usdjpy`)
   - 暗号資産: CoinGecko API(例: `https://api.coingecko.com/api/v3/coins/bitcoin/market_chart?vs_currency=usd&days=365&interval=daily`)を WebFetch。レート制限時は主要銘柄(ウェイト上位)に絞る
4. **計算**(python3。取得データを一時ファイルに保存してから処理する):
   - **概算ウェイト**: 数量 × 最新価格(米国株・暗号資産は USD/JPY で円換算)→ 全資産合計に対する各銘柄・各資産クラスの比率
   - **相関行列**: 日次リターンの相関(全銘柄ペア)。特に「AI関連グループ(5803/6594/6988/3915/NVDA/IONQ)内の平均相関」「暗号資産14銘柄のBTCとの平均相関」「安定軸(8306/9432/9697/4005)とAI群の相関」を要約
   - **テーマ集中**: `theses/_portfolio.md` の因子マッピングに基づき、同一因子への合算ウェイト
5. **判定**: `theses/_portfolio.md` の反証条件(相関<0.5 など)と照合し、「分散の錯覚」仮説が支持されたか棄却されたかを判定する。確信度+反証条件付きで。
6. **保存と記録**:
   - レポートを `reports/risk-DATE.md` に保存(ウェイト表・相関の要約表・テーマ集中・判定・計算方法と出典・免責)
   - `DECISION_LOG.md` の該当宿題(「相関実測」「テーマ集中」等)に「結果」行を追記
   - `theses/_portfolio.md` の該当項目を実測値で更新し、「見立ての変遷」に1行追記
7. **チャット報告**: 資産クラス別ウェイト / AI群・クリプトの実測相関 / 「分散の錯覚」判定 / 推奨アクション(あれば)を要約する。

## 注意
- 相関は期間・頻度に依存する。計算条件(期間・日次/週次)を必ずレポートに明記する。
- 取得不能な銘柄があっても中断しない。「取得不能(試したソースと理由)」を記録して残りで計算し、カバレッジ(全体の何%を計算に含めたか)を明記する。
- 数量×価格の概算であり、正確な口座残高ではない旨を明記する。これは情報整理であり投資助言ではない。
