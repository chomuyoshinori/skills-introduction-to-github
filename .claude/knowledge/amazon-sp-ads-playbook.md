# Amazon SP広告（スポンサープロダクト広告）入門 プレイブック（セミナー学習ノート）

初心者向けの SP広告 基礎運用。キャンペーン設定〜ターゲティング〜入札・予算〜30日最適化まで。
出典：社内セミナー資料「SP広告入門」（90分）。`marketing-specialist` / `data-analyst` の広告運用の土台。
広告のAI自動化（`amazon-ai-automation-playbook.md` / `amazon-oem-ai-playbook.md`）は本手動運用の理解が前提。

---

## 0. なぜSP広告か

- Amazon.co.jp の月間訪問者は約5億回超（2024年）、出品数は数億点 → **検索1ページ目に出なければほぼ買われない**。
- 新規出品は「実績ゼロ」で自然検索上位に出にくい → SP広告なら**出品直後から検索上位に表示できる**。
- 重要サイクル：広告でアクセス増 → 購入（CV）増 → **自然検索順位が向上** → さらに売上増。
- 結論：**SP広告は「売上の起爆剤」**。Amazonで成功するための最初の一手。

**Amazon広告は4種類 — 初心者はまずSPから**
| 種類 | 特徴 | 難易度 |
|---|---|---|
| スポンサープロダクト（SP） | 商品単位で出稿。検索結果・商品ページに表示 | ★☆☆ 初心者向け |
| スポンサーブランド（SB） | ロゴ＋複数商品。認知向上 | ★★☆ |
| スポンサーディスプレイ（SD） | Amazon内外にリターゲティング | ★★☆ |
| Amazon DSP | 購買データを使う高度ターゲティング | ★★★ |

**SP広告の本質**：① クリック課金制（CPC。表示だけなら無料、最低約2円〜・平均5〜10円）② 検索連動型（Amazonに来る人は「買いに来た人」＝購買意欲が高い）③ 商品ページへ直接誘導（1〜2クリックで購入完了）。
**掲載場所**：検索結果上部（1〜4枠・最も目立ちCTR高）／検索結果中段・下部（低入札でも表示可）／**競合の商品詳細ページ下部**。「スポンサー」表示だが見た目は通常商品とほぼ同じ → 広告と意識されずクリックされやすい。

## 1. 広告前の前提条件（ページを整えてから出す）

☑ 大口出品プラン（小口は広告不可）☑ **カートボックス獲得**（広告表示の必須条件）☑ 在庫あり（切れると自動停止）☑ 商品名60字目安で明確 ☑ 高画質画像4枚以上（1,000px以上）☑ 箇条書き3点以上 ☑ レビュー3.5以上・5件以上（可能なら）☑ 競争力ある価格。
> **ページ品質が低いと広告費をかけても購入につながらない**（CVR編プレイブック参照）。

---

## 2. キャンペーン設定（6ステップ・慣れれば5〜10分）

① Amazon Adsにログイン→「キャンペーンを作成」② SP広告を選択 ③ キャンペーン設定（管理しやすい名前／開始・終了日（終了なし推奨）／**1日の予算は最初1,000〜3,000円**）④ ターゲティング（オート or マニュアル）⑤ 広告グループと商品 ⑥ キーワード・入札額を設定して開始。

---

## 3. ターゲティング戦略（王道＝オートで学びマニュアルで磨く）

| | オート | マニュアル |
|---|---|---|
| 難易度 | 簡単（Amazon自動） | やや複雑 |
| 向く場面 | 始めたばかり・データ収集 | 成果KWが判明後 |
| メリット | 手間少・幅広リーチ | 無駄が少ない・高精度 |
| 推奨期間 | **最初の2週間〜1ヶ月** | オートの成果KWを移行 |

→ **オートで2週間 → 検索ワードレポートを見てマニュアルへ移行**。

**オートの4マッチタイプ**（例：いちごジャム）：ほぼ一致（「ジャム」）／おおまか一致（「パン」「朝食」）／代替商品（ブルーベリージャムのページ閲覧者）／補完商品（食パン・バターのページ閲覧者）。**最初は4つ全てONにして、後で不要をOFF**。

**マニュアルの3マッチタイプ**（例：赤いスニーカー）：部分一致（最広）／フレーズ一致（中）／完全一致（最狭）。入札額は**完全一致＞フレーズ＞部分**の順で高く。3タイプ同時登録で比較テスト推奨。

**商品ターゲティング**：カテゴリーターゲティング（新商品・認知向上向き。星4以上/Prime対応等で絞込可）／個別ASIN（競合対策・精度重視。競合の人気モデルのページに自社商品を表示）。

**除外設定＝広告費の無駄遣い防止装置（必須）**
- 無関係な検索への表示を防ぐ（例：カメラレンズ販売中→互換性のないカメラASINを除外）。
- 除外マッチタイプ：フレーズ一致／完全一致。
- タイミング：①キャンペーン作成時 ②運用後に検索ワードレポートを見て追加。

## 4. 入札・予算

- **入札戦略は「動的な入札（下降のみ）」から**：CV可能性が低い時だけ下げる＝ROAS重視・初心者向け。
  （上昇と下降＝CV最大化優先／固定＝上級者向け）
- 掲載枠別調整：検索結果上部・商品ページとも0〜900%上乗せ可。
- **予算は1日1,000〜3,000円から**（例：3,000円×30日＝月最大9万円）。予算超過が頻発→予算増 or 入札減。1日の途中で止まる→機会損失。**小さく始めてデータで拡大**。

---

## 5. 効果測定（週次5指標＋最重要レポート）

| 指標 | 意味 | 目安 |
|---|---|---|
| インプレッション | 表示回数 | 少なければ入札・予算を見直す |
| CTR | クリック率 | **0.3〜0.5%以上** |
| CPC | クリック単価 | 利益率と比較して判断 |
| ACoS | 広告費÷広告経由売上×100 | **目標ACoSは利益率以下**（例：利益率30%→ACoS30%以下） |
| ROAS | 広告経由売上÷広告費 | 高いほど良い |

**検索ワードレポートが最重要（毎週確認）**
- 売上多くACoS低いKW → **入札を上げ、マニュアルに追加**。
- クリック多いのに売上ゼロ → **除外キーワードに追加**。
- 他：ターゲティングレポート（入札調整根拠）／広告商品レポート（低効果商品の見直し）／掲載枠レポート。

## 6. 最初の30日プラン

- **Week1**：オートキャンペーン1つ作成（予算1,000〜3,000円・動的下降のみ）。**この週は設定を変えずデータを集める**。
- **Week2**：検索ワードレポートをDL、クリック多いKW確認、明らかに無関係なKWを除外。
- **Week3〜4**：成果KWでマニュアルキャンペーン作成、オートと並行運用、入札・予算を成果に応じ調整。

**初心者の5つの失敗と対策**：広告費だけかかる→ページ品質を先に改善／予算即枯渇→入札下げ or 予算増／ACoS高すぎ→除外設定強化／インプレッションゼロ→入札上げ・カート獲得確認／オートのみで頭打ち→成果KWをマニュアルへ。

**勝てるキャンペーン構成（カテゴリーごとに分けて管理）**
- ①オート（データ収集用）②マニュアルKW（成果最大化：ブランドKW/カテゴリーKW）③マニュアル商品（競合対策：競合ASIN/カテゴリー）。
- 同カテゴリー・同価格帯を同じ広告グループに。**価格差の大きい商品を混ぜない**（ROASが混在）。

---

## 7. 5つの原則（総括）

1. **商品ページを整えてから広告を出す**（広告は集客ツール。ページが悪ければ広告費が無駄）
2. **まずオートでデータを集める**（2週間〜1ヶ月が次の戦略の土台）
3. **検索ワードレポートを毎週確認**（成果KW→マニュアルへ、無駄KW→除外へ）
4. **ACoSを目標利益率以下に保つ**（広告費が利益を超えないKPI設定）
5. **小さく始めて成果を見ながら拡大**

次のステップ：SP深化（入札最適化）→ SB広告 → SD広告 → A+コンテンツ → Amazon SEO。
