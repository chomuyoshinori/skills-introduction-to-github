# リサーチの教訓集（動画分析からの学習ノート）

YouTube動画（中国輸入OEMリサーチ解説）を外部AIで分析・要約した教訓を、オーナーが持ち込み知識化したもの。
既存プレイブックを**補強・修正する「判断の原則」**として全専門家が参照する。
取り込み日：2026-07-06。出典：オーナー提供の動画分析メモ。

---

## 大原則：「商品を探す」のではなく「売れている理由」と「未充足の不満」を探す

- Amazon公式の **Product Opportunity Explorer** も、検索・購入・レビュー・価格・返品データから
  需要と未充足ニーズを見つける設計になっている。
- 感覚ではなく「**需要／競合／レビュー不満／価格帯／返品リスク**」を見て商品開発するのが本筋。
- 一言で：**「売れているのに不満が残っている商品」を見つけて、少しだけ改善してブランド化する。**

---

## 教訓1：丸パクリしていいのは「型」であって、商品そのものではない

- 真似してよいもの：リサーチの順番／売れている商品の見方／レビュー分析の視点／商品ページ構成／差別化ポイントの作り方／価格帯の決め方。
- 真似してはいけないもの：**ブランド名・ロゴ・意匠・画像・説明文・商品設計のコピー**（知財侵害・規約違反）。
- Amazonブランド登録は商標と密接：**出願中または登録済みの商標が必要**。
- → `ethics-compliance` / `legal-advisor` の管轄。「丸パクリOK」系の言葉は実務では危険ワードとして扱う。

## 教訓2：勝てるのは「大ヒット商品」ではなく「中ヒット＋不満あり」

| 見るポイント | 良い状態 |
|---|---|
| 需要 | すでに売れている |
| 競合 | 強すぎる1社独占ではない |
| レビュー | 低評価に改善余地がある |
| 価格 | 安売り勝負になっていない |
| サイズ | 送料・保管料が重すぎない |
| OEM | 少し変えるだけで差別化できる |

- 中国輸入OEMの共通整理：「売れているか」「一強市場ではないか」「中国OEMできて価格差が取れるか」。

## 教訓3：レビューは宝の山。ただしレビュー操作は絶対NG

- 見るべきは星5ではなく**星1〜3の不満**：壊れやすい／説明書が分かりにくい／サイズが合わない／梱包が弱い／部品が足りない／写真と違う／使い方が日本人向けでない。
- 1〜2個の改善だけでOEMの価値になる。
- ⚠️ **報酬付きレビュー依頼、レビューの作成・編集・削除の依頼は Amazonカスタマーレビューポリシーで禁止**。
  → **レビューは「分析対象」であって「操作対象」ではない。**

## 教訓4：売上（月商）ではなく「残る利益」で見る

- 年商・月商の数字に惑わされない。リサーチ段階で「**1個売っていくら残るか**」を先に計算する。
- 見るべきコスト：仕入原価／国際送料／関税・消費税／Amazon手数料／FBA保管料／広告費／**返品率／不良品率／値下げ余地／在庫回転**。
- 売上が立っても広告費・送料・返品で利益は消える（既存の「利益率30%基準」に返品率・不良率の観点を追加）。

## 教訓5：商標とブランド登録は後回しにしない（順番が大事）

1. ブランド名を決める
2. **商標調査・出願**する
3. **商品またはパッケージにブランド名を入れる**（ブランド登録では商標表示のある画像も求められる）
4. Amazonブランド登録する
5. 商品ページをブランド資産として育てる

→ OEM設計の段階から「パッケージに商標を表示する」前提で進める。

## 当事業への落とし込み：初手の優先カテゴリー（オーナー検討メモ）

オーナーの関心領域（アウトドア・家具・棚・農機具系・料理系・DIY系・業者向け消耗品まとめ売り）に対する提案：

| 優先度 | 商品方向 |
|---|---|
| 高 | 業者向けの小型消耗品セット |
| 高 | DIY用の補修・固定・収納パーツ |
| 中 | アウトドア小物の改良版 |
| 中 | キッチン周辺の非電気・非食品接触系 |
| 低 | 大型家具、電気製品、子ども用品、食品接触が強い商品 |

- 理由：初期ロット・送料・不良リスク・**法規制リスク**（PSE・食品衛生法等）を抑えやすい。
- 最初は「**レビュー不満を1つ改善しただけの商品**」が良い（ネジ不足／説明書が雑／収納袋が破れる／サイズ表記が不明瞭 等の改善だけで日本市場では差別化になる）。

### ⚠️ デカ重戦略との関係（司令塔メモ：戦略上の緊張点）

- `amazon-dekajuu-playbook.md` は「大型・重量物こそブルーオーシャン（FBA制限＝参入障壁）」を中核戦略とする。
  一方この教訓は「初手は小型・低リスクから」を推す。**両者は矛盾ではなく時間軸の違い**として整理する：
  - **短期（学習・検証期）**：小型・低リスク商品で「リサーチ→OEM→出品→広告」の一連の型を低コストで回して習熟する。
  - **中期（本命）**：物流コンサル連携の強みを活かし、デカ重（業務用・法人向け含む）へ本格参入する。
  - なお「業者向け消耗品まとめ売り」「業務用パーツ」は**両戦略の交点**（小さく始めつつ法人・業務用の勝ち筋を学べる）。
- どちらを初手にするかは**オーナーの資金・時間・リスク許容度による意思決定事項**。提案時は両案を併記する。

## オーナー定義のスクリーニング基準（2026-07 追加）

候補商品の一次絞り込みは、推定値ではなく **Amazon実画面で確認できる実売シグナル**で行う：

1. **実売数**：商品ページの「過去1ヶ月で〇〇点購入」バッジが **100点以上**（SellerSprite等の月間販売"推定値"より実バッジを優先）
2. **ランキング**：**大カテゴリーのBSRが2,500位以内**
3. 上記を満たした商品についてのみ、星1〜3レビューの不満分析 → 改善可否 → 利益計算へ進む

運用：オーナーがAmazon実画面のスクリーンショット（購入バッジ・ランキング・低評価レビュー）を提供し、
チームが不満分類（品質/説明/サイズ/梱包/付属品/デザイン）→ 改善仕様変換 → 提案書化を担当する。

## 実行チェックリスト（リサーチの標準手順）

1. Amazonで候補カテゴリを3つ選ぶ
2. 各カテゴリで売れている商品を20個ずつ見る
3. **星1〜3レビューを最低100件読む**
4. 不満を「品質・説明・サイズ・梱包・付属品・デザイン」に分類する
5. 同じ不満が何度も出る商品だけ残す
6. 中国工場または国内仕入れで改善可能か見る
7. **送料込みで利益率30%以上**を狙えるか計算する
8. **商標名とパッケージ表示を前提に**設計する
9. 最小ロットでテスト販売する
10. **広告費を含めて黒字化**できるか確認する
