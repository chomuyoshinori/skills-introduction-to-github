# 銘柄テーゼ集(theses/)

保有銘柄ごとの「**なぜ持っているのか(投資テーゼ)**」の原本です。
日次レポートが「その日の状況」を写すのに対し、ここは**時間が経つほど価値が増す蓄積資産**として運用します。

## 運用ルール
1. **1銘柄1ファイル**: `jp-<証券コード>.md` / `us-<TICKER>.md` / `crypto-<TICKER>.md`。横断テーマは `_portfolio.md`。
2. **検証済みの結論だけを反映する**: テーゼの更新は、レッドチーム検証を通過した後に report-editor が行う(未検証の分析を直接書き込まない)。
3. **各アナリストは分析前に対象銘柄のテーゼを読み**、「前回見立てとの差分」の基準にする(毎回ゼロから書き直さない)。
4. **「見立ての変遷」は追記式**(最新が上)。過去の行は書き換えない — 後から自分たちの判断を検証するための記録。
5. スタンス・確信度・反証条件に変化がない日は更新しない(ノイズを増やさない)。
6. 新規銘柄はこのREADMEのテンプレートから作成する。売却した銘柄はファイル冒頭に「クローズ(YYYY-MM-DD)」と記して残す(削除しない)。

## テンプレート
```markdown
# [コード/TICKER] 名称 — 投資テーゼ

- **資産クラス/枠**: 日本株(中リスク)/ 米国株(中リスク・枠内高リスク)/ 暗号資産(高リスク)
- **保有**: 数量
- **基準日**: YYYY-MM-DD / 最終更新: YYYY-MM-DD

## テーゼ(なぜ持つのか・3行以内)

## 中期スタンス
注目/保有継続/様子見/要警戒/撤退検討 | 確信度: 高/中/低/極低

## テーゼの前提(数値は時点付き)

## 反証条件(これが起きたらテーゼは崩れた=見直す)

## 次のカタリスト(日付付き)

## 見立ての変遷(追記式・最新が上)
- YYYY-MM-DD: 〜
```
